## 统一封装

- **请求封装**：全部 77 个 api 函数走 `call(() => invoke(...))`，错误统一换 `ApiError`
- **错误处理**：`ApiError`（code + message）+ `errorText()` 取展示文案
- **状态管理**：TanStack Query（服务端状态缓存/失效）+ Zustand（7 个 store：auth/recents/theme/toast/ui/workbench/ai）
- **失效策略**：写操作成功后 `queryClient.invalidateQueries` 按域失效（如 useMilestoneActions 的 CRUD 失效 `['projects','milestones']` + `projectKeys.all`）

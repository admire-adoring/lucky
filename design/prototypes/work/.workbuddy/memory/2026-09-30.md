# 2026-09-30 · 工作模块原型

## Bug 页：新增 / 编辑 / 删除（维护能力）
用户口径：「bug的新增编辑维护页面」。

### 形态：右侧**抽屉**，不是独立页
判据：**填的时候要不要一边看着清单**（对照）—— 改严重度时想比一比"还有哪些致命" ⇒ 抽屉（清单还在背后）。
**"字段多不多"不是选整页的理由** ⇒ 已把这条纠正写回技能 `inline-row-actions`（§六·五 开头 + 新增 §六·七）。
同模块已有同族抽屉（账户页 `.ac-drawer`）⇒ 本页叫 `.bug-drawer*`（改名只为搜 `.bug-` 时不漏），
表单控件（`.field` / `.inp` / `.chip` / `.chip-row`）**直接复用源页那一族**：两个页面的输入框长得一样。
层次：抽屉 190 < 弹窗 200 < Toast 300；ESC 按这个顺序**从最上面那一层**退。
⚠️ ESC 与命令面板分派那两段文本长在**源页**里 ⇒ 只能走 `rep()`，不能走 `sub()`。

### 表单（8 格）
标题 / 严重度 / 状态 / 模块 / 负责人 / 来源 / 复现步骤 / 环境。
- **必填只有"这一页存在的理由"**：标题 + 复现步骤（这页承诺回答的就是"坏在哪、怎么复现"）。
- **编号不进输入框**（系统已知的值）⇒ 底部只回显"保存时自动生成（下一条 BUG-1043）"。
- 封闭集合给胶囊（严重度 4 / 状态 3 / 来源 4），**`data-v` 与 SEV / GROUPS / SRC 的 key 同源**（探针断言相等）；
  开放集合（模块 / 负责人）用 `<input list=...>` + **现算的 datalist** —— 给建议不给约束。
- 渲染侧补三条空值护栏（`steps` / `env` / `own`）：**新增出来的数据一定比既有的更不完整**。
- `days === 0` 改说"今天刚报"（不是"0 天没动"）。
- 删掉展开区那枚「指派」：它的能力被编辑表单整个包含，两枚按钮做同一件事 = 同一层级的归类出现两处。

### 行级动词抽成六个（advance 与保存表单共用）
`listOf / paintRow / moveRow / rebuildRow / addRow / removeRow` —— 状态流转现在有两处入口
（行尾推进 + 编辑改状态），内联写两份必然走散。
- 编辑保存：只重造**那一条**（`replaceWith`）+ 恢复它原来的展开态；状态变了才搬组（搬节点，不重渲）。
- 新增：数据 `unshift` + DOM `insertBefore(..., firstChild)` —— **两处同序**，否则整组重渲后它跳位置。
- 删除：走二次确认弹窗（danger 按钮 + `modal-warn` 说清后果）。`--border-field` 与 `.btn-danger` / `.modal-warn`
  在这一轮之前被删过（"本页没有表单/没有破坏性操作"）⇒ 现在都恢复。

### 跨页（与任务列表）
- **快照要跟着改**：`syncPromoted()` —— 改标题/严重度/来源/最后一步复现 ⇒ 同步更新 localStorage 里那份副本。
- **删了不留死链**：任务行**留着**（"要做的这件事"是另一个决定），标 `orphan: true`；
  任务页据此不渲染「回到 BUG-xxxx」、注解 title 改成"原 xxx 已删除"。确认弹窗里把这个后果写出来。
- 跨页契约：写端 7 字段 ⊇ 读端 8 字段（含 `orphan`）✓；任务页重跑 **diff 只动预期三处**。

### ⚠️ 顺手修掉一处真实的"旧值"
侧栏「最久」原来只在首屏灌一次 ⇒ 新增/删除/改严重度之后停在旧值。**并进 `sync()`**
（判据：会变的值必须能被同一个 sync 重算出来）。页面级空态（`.bug-empty`，虚线框）也并进 sync ——
全删空时"空组不渲染"会把四张卡一起收走，只剩仪表条，读者会以为页面坏了。

### 探针新增 18 条（3c 段，专治"点了没反应"与"两处走散"）
字段齐 12 / 链路函数定义 23（少一个 = 界面正常、按了没反应）/ 弹窗五锚点 / 三组胶囊与常量表同源 /
编号不是输入框 / 两个容器默认 hidden + 各自的 `[hidden]` 兜底 / 复现步骤是 textarea /
三枚动作与 JS 分支一一对上 / 危险按钮与影响提示有样式 / 新增落位两处同序 / 侧栏与空态并入 sync / 删除标 orphan。
**踩到一个假阳性**：按固定窗口长度（1400 字符）抓 `#bfSev` 的 `data-v`，把并排的下一组一起收进来
⇒ 改成"**抓到该容器自己的 `</div>` 为止**"（能这么做的前提：`.chip-row` 里只放 button，没有嵌套 div）。

### 验证
Bug 页探针 ALL GREEN（含新加 18 条）；任务页探针 0 条不合格；两页 `node --check` 通过；
构建期两条结构断言（kpi-bar / bugGroups 在 `.detail` 内、整页 div 净深度 0）都过。


## 追加：用户问「在 bug 页我要怎么新增编辑 bug」—— 入口藏太深 + 一批没兑现的承诺

### 事实
「报告 Bug」原本只在**两处二级入口**：侧栏「快捷」面板（**默认不激活**，默认是「最久」）+ ⌘K（要先知道快捷键）。
而 Hero 右侧常驻的是「编辑项目」「最后检查」「进度」「截止」——**没有任何新增入口**（响应式注释里甚至写着
"Hero 右半（报告 Bug）"，当初打算放却没落）。

### 修（判据：这一页唯一的高频写动作必须常驻）
- Hero 右半加常驻 primary「报告 Bug」（主按钮放末端，与抽屉 footer 同一约定）；
  旁边那枚「编辑」→「**编辑项目**」（消歧：行展开区那枚「编辑」是编辑这一条 Bug，同名不同层级会被当成同一个）。
- ⌘K 面板：13 条键位提示（`G N/G 1..3/G D/G T/G C/G L/G W/G S/G P/G K/G ,`）**原本一条都没实现**
  ⇒ 实现「↑↓ 移动高亮 / Enter 执行 / G + 键 直选」序列（与提示一一对应；G 只在输入框为空时当序列键，
  否则想搜 "grid" 时第一个字母会被吃掉）。
- 两条**没有 `data-goto` 的死条目**（「任务清单」「工作」）接上真去处（跳任务页 / "已经在这个模块里了"）。
- 输入框 placeholder 写着"或输入命令"却**没有过滤** ⇒ 补 `filterCmd()` + `.cmd-item[hidden]{display:none}`
  （`.cmd-item` 自己写了 display，不补这条过滤"看着没反应"）；开合时重置过滤态；
  高亮要落到**第一条还看得见的**上（否则回车执行一条已被筛掉的条目）。

### 探针新增（3d 段 8 条）
Hero 有常驻入口 / 「编辑项目」消歧 / 面板 13 条都有去处 / 键位形式统一且**两两不同** /
键位有实现 / 过滤有实现 + `[hidden]` 兜底。
⚠️ **两个自伤**：① 用前缀类名 `class="cmd-item[^"]*"` 抓条目，把 `.cmd-item-icon` / `.cmd-item-text`
一起当成条目 ⇒ 假报"26 条没有 data-goto"；改成逐行取。② 前一轮按固定窗口长度抓 `#bfSev` 同理。
③ 改 `openCmd/closeCmd` 时忘了它们长在**源页**里（不在构建脚本源码中）⇒ 必须走 `rep(script_shell, ...)`，
用 `sub()` 会直接 assert 失败（好在失败得早，没写坏文件）。


## 追加 2：入口位置修正（用户：「放在下面」）
「报告 Bug」先前被放到 Hero 右侧 ⇒ 用户一句「放在下面」⇒ 位置**层级不对**：
Hero 那一排是**项目级**的（编辑项目 / 重新检查 / 进度 / 截止），而它是**本分区**的动作。

**判据（新，已写进技能）：动作要和它作用的范围在一起。**
它跟 Tab 条走 ⇒ 放 Tab 条**下面那一行**（`.bug-toolbar`，在 `kpi-bar` 之前）。
- 顺序已断言：tab 条 → 工具栏 → 仪表条 → 分组容器 → 空态 ✓
- 间距：`margin-top: -8px` 把「Tab 条 ↔ 工具栏」收到 12px，而「工具栏 ↔ KPI」仍是 20px
  （判据：**组距 > 项距** —— 它跟 Tab 条是一组，都在说"当前这个分区"）
- 不给底色：它是一条**控件行**，不是一张卡
- `.hero-bar-right` 那排只留「编辑项目」；探针断言**它不含 `openBugForm`**（防止再混回去）
- 探针 3d 段改成两条：工具栏里有常驻入口 / Hero 只放项目级动作

⚠️ 自伤一次：改探针那几行时字符串里内嵌了双引号 ⇒ Python 语法错 ⇒ 整段没写盘
（好在先跑构建、后跑探针，构建已经生效，所以只补跑探针）。**探针脚本也是代码，同样要过语法。**
⚠️ 另一处误判：用整个 `s` 量 "Hero 里有没有 openBugForm" 时，`hero-bar-right` 在 **CSS** 里先出现
⇒ 范围从 `<style>` 开始，跨到 body 里的 `id="moreMenu"`，把工具栏也圈进去了（假 True）。
**量标记必须用 `markup`（body→script）**，不能用整页文本。

## 项目详情 · 总览：把「六条横带」做成一排有形状的东西

用户判词三个字：**「太普通了」**（上一轮的六条横带：图标 + 名字 + 徽标 + 一句灰字 + 箭头，
六条一模一样）。`工作-项目-项目详情-总览-index.html`：3083 → 3163 行 / 180 KB。

### 判据：什么叫"普通"（可执行的那一条）

**一批条目同形、同重、同节奏 ⇒ 读者找不到视觉起点，读成"设置列表"。**
破法**不是**加点缀（渐变 / 阴影 / 彩色底 —— 那是"给面加材质"，与"这批条目没有形状"是两件事），
而是**让每条长成它自己那条数据的形状**：

| 行 | 数据 | 图形 |
|---|---|---|
| 任务 | 26 / 36 | 一条进度条（填 72%） |
| BUG | 1 条致命待修复 | 一枚告警三角 |
| 文档 | 最近三本 | 三根书脊（中间那根亮一档 = 刚更新那本） |
| 运维 | 2 台服务器 | 两枚机架（上面那枚亮一档 = 运行中那台） |
| 会议 | 11 月 5 日 | 一个日期块（5 / NOV） |
| 账户 | 3 个平台 | 三枚方块（最左那枚 = 生产） |

三条配套（少一条就走样）：
1. **槽宽固定 72px、图形右对齐** —— 否则六行图形宽窄不一，左边那句结论被推得参差；
2. **图形不许超过身份图标那 24px** —— 超了会把那一行撑高，六行的发丝线就不等距
   （本轮踩：日期块先做成 30px，会议那行比别行高 6px，像"这一行更重要"）；
3. **形状必须从这条自己的数据来**。装饰性图形读第二遍就没有信息，还会把结论句挤小 ——
   `.ov-day` 里那个 `NOV` 只有 6.5px（不可读），它要的只是"一眼认出这是个日子"，
   完整日期在结论句里（"11 月 5 日 14:00"）。

### 另一件事：六条独立浮卡 → **一块面板**

六张各自带描边与阴影的卡会把"同一个项目的六个面"拆成六个平级条目 ⇒
改成一个外框 + 内部发丝线（`.ov-item + .ov-item { border-top }`）+ 行悬停底。
面板 `overflow:hidden` 带来两处连带：行内 `:focus-visible` 的 outline 要 `-2px`（不然被裁），
异常那道的左沿色条要用**伪元素**（`inset` 阴影会被 `is-spot` 的动画整条覆盖）；
也**不能**用 `border-left`（内容右移 3px）。

### 又踩了一次「锚点里带母页的数据」（昨天刚写进技能的那条）

`TABS_DOM` 那组替换的锚点是 `' Bug <span class="tab-count">2</span>'` ——
**运维页的 tab 计数从 2 改成了 12**（别人做的），整组静默失效。
⇒ 锚只到「标签名 + 计数格的引号」为止，数字由本页写：
`re.subn(r'(%s <span class="tab-count")>[^<]*</span>' % 标签, …)` + `assert _n == 1`。
（同一天里出现的第二处 —— 这条定律适用于**任何"锚点里带了母页一个数"的地方**：
侧栏副标题、tab 计数、卡片徽标、面包屑…）

全绿：探针 12 组 + `node --check` + 收尾断言（新增"六行图形恰好六个、且六个定义都在"）。

## 同一页第三轮：「表格卡片的样子」

用户判词四个字：**「表格卡片的样子」**。`工作-项目-项目详情-总览-index.html`：
3163 → 3192 行 / 182 KB。

### 判据：这是对上一版**列对齐**的诉求，不是"换回表格元素"

上一版六行是 `flex` **顺序排**：`数量`跟着名字宽度走、`此刻`跟着徽标宽度走
⇒ 两列的起点**一行一个位置**（那不叫表格）。
改成 grid 六列（`24px 44px 152px minmax(0,1fr) 72px 24px`）+ 一条表头：
`分区 / 数量 / 此刻`（第一个格 `grid-column: 1 / span 2`，因为"图标+名字"合起来才是分区）。
列对齐之后，六行的每一列上下都齐 —— 这才是"表格"的全部意义。

**关键一条**：列宽写成 `.ov-list` 上的**一个变量**，表头与六行读**同一份**
（`assert HTML.count('--ov-cols:') == 2 and HTML.count('var(--ov-cols)') == 2`）。
两处各写一遍 = 改一处就错位，而错位只有肉眼看得出来。

### 这一轮踩的三个"命名 / 断言"坑（都不是逻辑错，全是静默的）

1. **新类名撞了"上一版的禁用清单"**：表头本来叫 `.ov-head` —— 而那正是**六张卡墙时代卡头**
   的名字，收尾断言里正躺着一条 `assert 'ov-head' not in HTML`（防旧版回来）。
   ⇒ 改名 `.ov-thead`。**连带一条更阴的**：我第一次在注释里写了「上一版卡头就叫 `.ov-head`」
   —— 注释也被那条断言抓（它是 `in HTML`，不分标记/样式/注释）⇒ **连注释里都不能写出那个全名**。
2. **新变量名撞了另一个组件的同名变量**：`.ov-list` 的列宽变量本来叫 `--cols` ——
   而**命令面板的 `.mega-grid` 已经有一支 `--cols`**（那边存的是列**数**：`repeat(var(--cols, 3), 116px)`）。
   两个同名的东西放一页上，改错一处不报错，只会"某一块突然排成一列"
   ⇒ 加页面前缀 `--ov-cols`。（与"新类名先和全页既有类求交集"同一条，**变量也要查**。）
3. **收尾断言写太死**：`assert HTML.count('.ov-bar {') == 1` —— 窄档给同一个图形再写一档尺寸
   （`.ov-bar { width: 34px }`）就变成 2 ⇒ 改成 `>= 1`。
   判据：**断言要盯"有没有"，不要盯"恰好一次"** —— 除非那个"一次"本身就是契约
   （列宽的 2 处就算契约，因为它俩必须同步）。

全绿：探针 12 组 + `node --check` + 收尾断言（含"六行图形恰好六个 + 表头与行共用同一份列宽"）。


## 追加 3：录入成本（用户：「不方便记录bug」）
这一句是硬伤 —— 我把录入做成了**一张 8 格申报单 + 两个必填**，而记 bug 的真实场景是**测试时随手记一句话**。

### 判据（新，写进技能 §六·十）
**一条记录的录入成本必须接近"打一句话"。**

### 改了什么
- **工具栏变成录入行**（原来是右对齐的一枚按钮）：
  `[一句话说清哪儿不对…] [记下来] [详细填…]`
  - 回车即存 ⇒ 落「待修复」组首；其余字段留空
  - **记完不滚动、不抢焦点**（随手记是连着记好几条的）⇒ 确认感交给 toast 上那枚「看它」
  - 「详细填…」= 另一条路（完整表单）
- **必填降到只有标题**：复现步骤从"必填"降成"建议"。
  ⚠️ 但缺了必须**可见** ⇒ 展开区显示"还没写复现步骤 [补上]"（`data-bug-act="edit"`），
  且 `openBugForm` 里焦点**落在缺的那一格**（`(b && !b.steps.length) ? 'bfSteps' : 'bfName'`）。
- **不填的留空、不猜默认值**：`QUICK_DEFAULTS` 只剩 `sev`/`state`（渲染上必须有值），**去掉了 `src`**；
  `bugRowHtml` 里 `SRC[b.src] || null`（原来兜底成"测试发现"= 替人下结论）。
- **补三个空值护栏**（关"渲染侧必须吃空值"）：行的第二行「模块 / 来源 / 负责人」**逐项条件渲染**，
  **分隔点跟在自己那一项前面** —— 否则一条只有标题的记录会显示成 `BUG-1043 · · ·`。
  负责人空 ⇒ "未指派"（斜体，它是待办不是"没这个字段"）。
- **⌘K 里搜不到就新建**：过滤后没匹配 ⇒ 露出一条 `#cmdNew`（`新建「<输入的那句话>」`），
  Enter 直接带标题打开表单。
  ⚠️ 抓输入文本必须在 `closeCmd()` **之前**（它清空输入框）⇒ 那次 rep 的替换范围要**扩到 `closeCmd();` 那一行**。
- **修一个真 bug**：过滤之后键盘还在遍历**全量**条目 ⇒ ↑↓ 会停在隐藏项上、回车把它执行掉
  （屏幕上什么都没有）。新增 `cmdVisible()`，键盘段改用它。

### 探针新增（3e 段 13 条）
快速通道在工具栏里 / 输入框自己说了怎么提交 / `quickAddBug` 有定义 / 必填只剩标题（`missSteps` 不许存在）/
保存兜底也只认标题 / 缺步骤有提示且带「补上」/ 焦点落在缺的那一格 / 来源不兜底 / 负责人空有交代 /
⌘K 有新建条目且默认 hidden / 带标题进表单 / 文本在 closeCmd 之前抓 / 键盘只走可见项。

⚠️ 自伤：**把两件事串成一个 `and`**（`'function openBugFormWithTitle' in js and 'new:quick' in js`）——
`new:quick` 是**标记**里的 data-goto，JS 里对应的是 `key === 'quick'` ⇒ 这条断言永远失败。
**跨"标记 / 脚本"两边的断言要分开写**，别串在一个条件里。

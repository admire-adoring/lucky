## 文件位置 UI 优化：单链压缩 + 读序（15:4x）

`opt` / `app` / `web` / `nginx` / `conf.d` / `sites-enabled` … 单独占一行、26px、共 **338px**，

⇒ 加 `routeMerge()`（地铁图的"区间合并"）：**一个节点只有 1 个孩子就把孩子并上来**（名字用 `/` 连），

两条边界：合并只在**真实同源**处（拼出来就是路径本身）；**节点自己挂着读数时不并**
（前缀路径 `/opt/app` + `/opt/app/web/dist` 并掉就把读数丢了）。

### ⚠️ 「卡片贴卡片」的根因不是间距，是**层级**（两处，正反面各一）
用户截图第二句：「都已经卡片贴卡片」（红框标在 Tab 条 ↔ KPI 卡、KPI 卡 ↔ 分组卡）。

| # | 错法 | 后果 |
|---|---|---|
| ① | `TABS` 新块**多抄**了一层 `</div>`（把 `.tabs` 自己的闭合和它外层 `.tabs-wrap` 的闭合一起写了） | `.detail` 提前关闭 ⇒ KPI 条与四张分组卡掉到 `<main>` 下成为直接块 ⇒ 块级之间**没有默认间距** |
| ② | `SLOT_BODY` 的替换区间 `[slot-body 开, sidebar-foot 开)` **吃掉了** `sidebar-slot` 的闭合行 | 侧栏那层永远不关（`sidebar-foot` 被吞进 `sidebar-slot` 里） |
| ③ | `#bugGroups` 这层中间容器**隔断了 `.detail` 的 gap**（`gap` 只作用在直接孩子上，三张卡是"孙子"） | 分组卡之间也没有间距 |

**判据（写进技能）：新块该含到哪一层，由"替换区间吃到哪"决定** ——
区间**不含**外层闭合 ⇒ 新块只许含自己的开与闭（抄了就是提前关一层）；
区间**含**外层闭合 ⇒ 新块必须补上（漏了就是外层永不关）。两处的值**必须跟引用它的那一档走**
（`#bugGroups` 的 gap = `.detail` 的 gap：20px / 窄屏 16px），否则迟早走散。

⚠️ 这个错**没有任何一条既有断言会报**：div 净深度终值仍是 0（多的一开一闭互相抵消）、
标签开合数也平衡；修好 ① 之后真相才暴露（净深度变 1，栈里只剩 `<div class="app">` 未闭合）。
⇒ 兜底两条，都加进构建脚本与探针：
· **在 seeder 之后**再验一次 `<body>` 的 div 净深度 == 0（页面模板里少一个 `</div>` 只有这条能抓）；
· 查"包多张 `.ops-card` 的中间层有没有 gap"（全仓扫过：只有本页有这种中间层）。
定位手法（可复用）：逐行累计净深度 → 与源页**同位置**对照逐行 diff → 标签栈看剩下哪一层。

顺手：`.kpi-bar` 列宽补 `minmax(0, 1fr)`（源页有、本页缺）—— `1fr` 的最小尺寸取 `min-content`，
第一格那种长文案会把整行撑破、页面横向溢出。探针 ALL GREEN（含新加的 5 条）。

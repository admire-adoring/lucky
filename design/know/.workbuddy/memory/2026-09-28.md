**问题**：我补全局图 / 时间轴时，为了让「主题 / Louvain 社区 / 标签」这些分组可区分，

**判据（值得记住）**：**界面色 = 令牌层（一个域色 + 状态色），数据编码色 = 同一色相的明度阶梯 + 暖色 + 中性灰。**

**改法**
- 删掉 4 个颜色常量（`DATA_COLORS_LIGHT/DARK`、`GROUP_COLOR_LIGHT/DARK`），改成 `dataColors()` / `groupColorOf()`
  **每次现取 CSS 变量**（`cssVarOf('--m-fill')` …），并按主题缓存（`dataColors._key`）——
  令牌改一处就生效，JS 里不再复刻色值。
- 8 档顺序按「对比度从强到弱」：最深青 → 暖 → 浅青 → 冷灰 → 中青 → 浅暖 → 更深青 → 浅灰。
- 三个主题组 = **深青 `--m-fill` / 浅青 `--m-line-strong` / 暖 `--warn-ink`**（明度差拉开，灰度下也能分）。
- 孤岛高亮 = `--warn-ink`（暖）· 枢纽高亮 = `--m-fill`（深青）· 其余一律 `--border-strong` 灰。
  原来孤岛用 #DC2626、枢纽用 #F97316，都换掉了。
- 时间轴的 `[data-group]` 色点（CSS 里的 #F97316 / #10B981）→ 令牌 var。
- `.sync-dot.err` 的 #B91C1C → `--warn-ink`。
- **保留** `#deleteConfirm` 的 #B91C1C：删除是"危险动作"的通用语义色，且项目 `.nav-p-badge.warn` 已用同一个红。

**自检**：扫全文件的 6 位色值，除令牌定义区与 `cssVarOf` 的兜底值外，只剩上面这一处刻意的危险红。

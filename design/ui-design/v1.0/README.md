# Lucky-Y UI 原型 v1.0

生活 / 工作 / 学习三域一体的个人管理系统 —— 登录与项目管理模块的高保真静态原型。

> **v1.1 交互补全**：实现「项目」「编辑」「删除」「更多」四个按钮的完整行为
> （下拉菜单、编辑表单、二次确认、撤销、禁用态），并补一层**仅保存在本地浏览器**的数据层，
> 让编辑与删除在刷新、跨页之后依然成立。行为规格见「按钮行为规格」。

## 文件清单

| 文件 | 页面 | 说明 |
| --- | --- | --- |
| `index.html` | 登录页 | 左侧品牌叙事面板 + 右侧登录表单；提交后跳转项目列表 |
| `projects.html` | 项目管理 | 应用主框架 + 统计 + scope 筛选 + 卡片/表格/看板三视图 |
| `project-detail.html` | 项目详情 | 通过 `?id=p1…p8` 取数，5 个标签页 |

均为**自包含单文件**（CSS 内联、无外部依赖、图标用内联 SVG symbol），双击即可打开，也可直接丢进静态服务器。

## 页面流

```
登录页 ──[登录 / GitHub 登录]──> 项目管理
项目管理 ──[点击项目卡片 / 表格行 / 看板卡]──> 项目详情 ?id=pX
项目详情 ──[返回项目管理]──> 项目管理
```

侧边栏中「生活 / 工作 / 学习 / 知识库 / 设置」为占位项，点击给出提示（v1.0 范围外）。

## 设计系统

### 色彩

| 语义 | Token | 值 | 用途 |
| --- | --- | --- | --- |
| 品牌 / 交互 | `--brand-500` | `#4f46e5` | 焦点环、链接、激活指示 |
| 主操作 | `--ink-900` | `#101218` | 主按钮底色（近黑，避免蓝按钮的通用感） |
| 生活域 | `--life` | `#0f9d76` | scope 标记、进度条 |
| 工作域 | `--work` | `#2f6fed` | 同上 |
| 学习域 | `--learn` | `#7c3aed` | 同上 |
| 成功 / 风险 / 警示 | — | `#0f9d76` / `#dc2626` / `#c2740a` | 状态 chip、逾期、风险块 |
| 中性阶 | `--ink-50…900` | 冷调灰 | 文字、边框、填充 |

**关键约定：三个 scope 各有一个语义色，贯穿 badge / 进度条 / 卡片左侧指示条 / 看板列头，是全局唯一的"归属"信号。** 品牌色只用于可交互状态，不用于大面积填充。

对比度：正文 `--ink-900` on `#fff` ≈ 17:1；`--ink-500` on `#fff` ≈ 5.1:1；`--ink-400` 仅用于 12px 以上的辅助信息（≈ 3.6:1，不承载正文）。

### 排版

- 字体栈：`-apple-system, "PingFang SC", "Microsoft YaHei", …`
- 字号：11.5 / 12 / 12.5 / 13 / 13.5 / 14 / 15 / 15.5 / 16 / 21 / 24 / 26 / 29px
- 正文行高 1.7，标题 1.3；数字统一 `font-variant-numeric: tabular-nums`
- 字重只用 500 / 600 / 650 / 700

### 间距与形状

- 4px 基准：`--s1`(4) `--s2`(8) `--s3`(12) `--s4`(16) `--s5`(20) `--s6`(24) `--s8`(32) `--s10`(40) `--s12`(48) `--s16`(64)
- 圆角：`6 / 8 / 10 / 14 / 20 / 999`px —— 卡片 14，控件 10，chip 22（胶囊）
- 阴影四档，卡片默认无阴影仅描边，hover 才升到 `--sh-lg` + `translateY(-3px)`

### 动效

- 时长：`150ms` 微交互 / `220ms` 常规 / `400ms` 页面级
- 缓动：`cubic-bezier(0,0,.2,1)` 为主，回弹用 `cubic-bezier(.34,1.4,.64,1)`
- 列表入场为 45ms 递增的 `fadeUp` 错位动画
- 全部动效已在 `prefers-reduced-motion` 下降级

## 组件与状态

| 组件 | 状态 |
| --- | --- |
| 按钮 | default / hover（上浮 + 阴影）/ active（缩 0.98）/ focus-visible 焦点环 |
| 输入框 | default / hover / focus（品牌色描边 + 3.5px 光环） |
| 项目卡片 | default / hover（上浮 + 左侧 scope 色条淡入）/ 逾期日期转红 |
| Scope 标签页 | 选中态白底 + 阴影，带数量角标 |
| 视图切换 | 卡片 / 表格 / 看板，三段式 seg control |
| 进度条 | 三档渐变填充（按 scope），0% 与 100% 均有正确表现 |
| 状态 chip | 待启动（灰）/ 进行中（绿）/ 风险阻塞（红）/ 已完成（紫） |
| 空态 | 筛选无结果时展示 |

**无障碍**：所有可点击元素 `tabindex` 可达、卡片支持 Enter 触发；`aria-label` 覆盖图标按钮；焦点环统一 2px 品牌色；触摸目标 ≥ 32px（收起的图标按钮 34×34）。

## 交互实现要点

- **搜索**：`projects.html` 顶部搜索框支持 `⌘K / Ctrl+K` 聚焦、160ms 防抖、匹配项目名/描述/标签/里程碑，三视图同步过滤
- **排序**：默认 / 截止日期最近 / 进度最高 / 优先级最高
- **响应式**：≥1240px 四列；1240–1024 统计两列、看板两列；≤860px 侧边栏抽屉化（汉堡按钮 + 遮罩）；≤600px 单列，表格横向滚动

## 开发落地建议

原型是 HTML + 原生 CSS 变量，迁移到 `shadcn/ui + Tailwind v4` 时：

1. 把 `:root` 里的 token 直接映射到 `@theme`，scope 色注册为语义色（`--color-life` / `--color-work` / `--color-learn`），这样 `bg-life/10 text-life` 这类工具类直接可用。
2. 圆角、阴影、间距已是 4px 栅格，对应 Tailwind 默认刻度，不必自定义。
3. 卡片用 `Card` + `CardHeader` 组合，scope 色条用 `::after` 伪元素（原型里的做法），避免额外 DOM。
4. 三视图切换建议不做路由，用 `view` 状态 + 懒渲染，保持滚动位置。
5. 状态名与后端对齐：`planning / active / risk / done`，优先级 `high / mid / low`，scope `life / work / learn`。

# 本工作区强制规则

用户在 2026-09-26 明确要求并将本条列为长期约定，作用域为本工作区全部后续对话，**无需每次重复声明**。

## 三条约束

| # | 约束 | 具体禁止 |
|---|---|---|
| 1 | 不做视觉验证 | 不截图；不启动浏览器/headless Chrome 做渲染校验；不做像素、对比度、几何回归等验证性测量；不产出"验证截图"类文件 |
| 2 | 不加额外说明 | 不写流程旁白（"我先…然后…"、"我这样做的原因是…"）；不加未请求的总结、建议、可选方案、下一步清单 |
| 3 | 不写不跑测试 | 不新建测试文件（unit / integration / e2e / 断言脚本）；不执行 test / lint / typecheck / 校验类命令来验证结果 |

## 交付口径

- 交付物做完即交付，**以"文件已写入 / 命令已执行成功"作为完成判据**，不做二次验证。
- 交付后最多给一行结果定位（改了哪个文件、产出在哪），到此为止。
- 编号 2 仅约束**未请求**的旁白与附加内容，不约束交付物本身必要的内容表达。

## 解除条件

仅当用户在**那一条消息里显式点名要求**某项（例如"这次帮我截个图"）时，临时解除对应条目，且只对该次生效；不修改本条长期规则。

## 项目卡：保持现状，不换成 v2 的抽屉形态（2026-09-26）

结论：**保持现状**。三条判据（都不是口味问题）：

1. **默认态读数**：v2 默认只给 3 项（名称 / 负责人 / N 个资源），文档缩略 `opacity: 0`
   悬停才浮现。而列表层要答的是"我有哪些项目、各自到哪了" ⇒ 需要默认可见的读数。

   并改成 `负责人 · 进度 N% · 剩余/归档`。
2. **材质与纯色口径冲突**：抽屉的信息全在材质里（柜体内凹 = 3 层 inset 阴影 + 2 段渐变、
   面顶高光、悬停下移 6px）。本文件已定死"面一律不透明、没有 α、没有 backdrop-filter"。
   纯色化之后只剩"空盒子 + 悬停才出现的 3 个小方块 + 一行名字"。
3. **同一枚举两套配色**：v2 的 `.p-rose/.p-purple/.p-cyan/.p-slate` 是"给 4 个样本随手配的
   点缀"（`ProjectDrawers.tsx` 原话），列表层现在用语义化的 `STATUS_BADGE`，且与详情 Hero
   共用同一张表。

**v2 的形态已有归属**：`/work/projects`（工作模块的「项目」分区，只列 `scope === 'work'` 的

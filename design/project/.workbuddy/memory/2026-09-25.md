## project_index.html：材质从毛玻璃 / 极光换成纯色

范围：只改 `client/lucky/design/project/project_index.html` 一个文件（用户指定）。
功能与结构未动，只换材质层 + 顺带补齐对比度。

### 令牌层（新面阶，亮暗各一套，只共用"浮起 = 变亮"这个方向）
- 页 `#ECF0F7` < 沉槽 `#F2F5FB` < 深槽 `#E7ECF5` < 卡面/外壳 `#FFFFFF`（亮）
- 页 `#0A1018` < 沉槽 `#111A26` < 深槽 `#0D1521` < 卡面 `#18222F`（暗）
- 线阶两支：`--line`（结构线）`--line-strong`（控件描边）；字阶三档重定。
- 删掉的旧令牌：`--bg-sidebar` / `--bg-topbar` / `--border-card` / `--border-subtle` /
  `--blur-card` / `--blob-opacity` / `--blob-blur` / `--a-projects-*` / `--s-projects` /
  `--m1..m3`，以及整层 `.aurora-bg` / `.blob-1~3` / `@keyframes drift`。

### 提示是"一色两档"，不是"每处各挑一个够深的"
高饱和亮色相挤不进"白字 4.5 + 图形 3"这个窗口（橙-500 两头都不到），
所以拆成同色相两档：`--m-main` 图形（`#EA580C`）/ `--m-ink` 文字与实底（`#B93E0B`）/
`--m-on` 实底上的字。四象限同样拆成 `--q*` / `--q*-ink` 两支。

### 图谱
节点身后的弥散光斑（`bloomDefs` 的径向渐变）与球体雾（`gb-body` / `sphere-body`）
整层删掉；`.gmap` 自己变成一块深槽画布（底色 + 1px 线）。
`bloomDefs()` 只剩箭头 marker，改名 `svgDefs()`。

### 两个踩到的坑（都已修）
1. 派生令牌（`--ok-bg = color-mix(..., var(--ok), var(--bg-card))`）在 `.dark` 里
   只覆写输入是不够的：`var()` 在声明它的元素上解析，`.dark` 挂 `<body>` 时
   会把亮色结果一起继承下来 ⇒ 派生令牌必须在 `.dark` 里原样再声明一次。
2. HTML 注释（`<style>` 之外）里写了 `<div class="aurora-bg">` 与 `--bg-page`，
   导致"标签平衡"核对报出一个不存在的未闭合 div，且违反注释体不得含 `--`。
   文档层注释只写自然语言。

### 未改的部分（有意保留）
`NOTES` / `TASKS` / `DOCS` / `REVIEW` 里的**数据文案**：
`n1 弥散风格 UI 设计笔记`、`n4 玻璃材质上的对比度实测记录`、`t3 实现弥散风格主题系统`、
`t10 定义 18 色弥散色板` 仍是旧材质的描述。它们读起来像项目历史（08-28 已完成、
08-30 记录），改成纯色描述等于改数据而不是换材质，所以留原样，已在回复里点出。

## project_index.html：导航栏换成「导航-v5」那一套（同一天第二轮）

参考件：`design/index/导航-v5.html`（顶栏一级胶囊 + 超级菜单 + 侧栏圆盘/图标列 +
三槽面板 + 命令面板）。只改 `project_index.html` 一个文件。

### 结构变化
- `.app` 网格：`240px | 1fr | 260px`，行 `68px | 1fr`，areas 改成 `topbar 通栏`；
  加了 `.app.sidebar-collapsed`（64px）与折叠按钮。
- 顶栏 = v5 药丸（logo + 9 个一级模块胶囊 + `.mega` 二级下拉 + 右侧图标组）；
  **其余 8 个模块只弹提示、不改 active、不重建环**（只有「项目」有内容承载）。
- 侧栏 = v5 卡片：head + 圆盘（9 格，就是原来那 9 个页签）+ 图标列（收起态）+
  三槽（最近 / KPI / AI）+ 收起。
- **旧的 9 个 `.tab` 页签 CSS / DOM / JS 分支整族删除**；新增 `.page-header`
  只放 `项目 / 当前分区`（末段 `.current`），右侧承接原顶栏的「归档 / 新建任务」。
- 右栏 `.aside` 改成"浮在页上"（它属内容不属导航）：去掉 `border-left`，卡片加阴影。

### 命名冲突（撞名的都改**模块这一侧**，导航壳要留给其它模块复用）
| 原 | 改后 | 原因 |
|---|---|---|
| `.rail*`（里程碑轨道） | `.msl*` | v5 的 `.rail` 是收起态图标列，同名会把整条轨道吃掉且不报错 |
| `.rail-task*`（右栏任务行） | `.aside-task*` | 上面改名的连带，避免 `.rail` 一词两义 |
| `.quick-btn`（右栏快捷） | `.aside-quick` | v5 槽里的 `.quick-btn` 是"实线描边 + 图标格"，形完全不同 |
| `.icon-btn`（复盘删除键） | `.del-btn` | v5 顶栏图标按钮就叫 `.icon-btn` |

### 令牌：不搬 v5 的 `:root`，改走 11 对别名
`--bg-float→--bg-card`、`--bg-subtle→--bg-slot`、`--bg-hover→--bg-deep`、
`--border-*→--line/--line-strong`、`--shadow-float→--shadow-pop`、
`--m-soft→--m-tint`、`--m-fill→--m-ink`、`--ink-on-accent→--m-on`。
导入段里的硬编码语义色（`#B91C1C` / `#EF4444` / `#10B981` / `rgba(239,68,68,…)`）
一起归位到 `--danger/--danger-bg/--ok`。

### 契约
`SECTIONS[].key` == `.panel[data-panel]`，**顺序也要一致**。
`activateTab(key)` 是唯一同步点（面板 + 圆盘 + 面包屑 + 槽）；圆盘点击只调它，
不自己写选中态；`renderRing` 里不许再调 `activateTab`（会递归）。

### 分区三个字段各去一处
`count` → 圆盘悬停名称条（短，240px 侧栏放得下）；`meta` → 侧栏副标题 + 收起态 rail tip
（浮在侧栏外，放得下全称）；`desc` → 页面副标题。三者都写成函数，随数据变。

### 有意保留
- 三级机制（`enterLevel3` / `backToLevel2` / `rail__back`）整段留着但**当前一次都不会触发**：
  9 个分区都没有 children（「列表/看板/四象限」是同一列表上的视图，已做成面板内 `.seg`）。
  保留是为将来给某分区加 `children` 时不用重写导航。中心门因此改成"回到第一格"。
- 数据文案同上（弥散 / 玻璃那几条）。

## ⛔ 硬坑（全在 `<script>` 区）
- **不写模板串、不写注释**：模板串里出现反引号 ⇒ 字符串提前闭合 ⇒ SyntaxError ⇒ **整页 JS 全停**（骨架在、JS 生成的全空）。一律拼接；引类名/函数名用「」。
- ⚠️ **字面的 HTML 注释记号更要命**：`<script>` 区里出现它 ⇒ 解析器进 "script data escaped" 态 ⇒ 之后脚本被当注释读 ⇒ **整段静默失效**。需要时 `'<!' + '--'` **拼**。
- ⚠️ **拼 HTML 不许用 `replace('…','…')` 打补丁**：命中位置不受控（实锤：命中前面那颗的结尾 ⇒ 标签配错 ⇒ `innerHTML` **重排整块**）。⇒ 传参数拼。
- **属性值只要不是字面量就必须 `esc()`**：值里的 `"` 提前闭合属性 ⇒ 后半截当正文并吞掉相邻按钮。⚠️ `node --check` **查不出来**。复核：把 `attr="' + 表达式` 全捞一遍。
- **"输入控件让路"收成一支 `isTypingTarget(el)`**：`INPUT`/`TEXTAREA`/`SELECT` **+ `el.isContentEditable`**。漏 tag ⇒ 键被吃；漏 `isContentEditable` ⇒ 可视正文里打数字键**换分区**。
- **一处判定，多个读它的人**：同一判据散在多处迟早分叉 ⇒ 收成一支（`edWysMarkEl`/`edCodeBoxAt`/`edWysRangeOffset`/`edTbAlong` 这一族）。
- **同一个东西别存两遍**（色值曾在 JS/CSS 各一份 ⇒ 字段错位）；**下标取值肉眼看不见**（改用对象字段）。
- ⚠️ **一份清单要"派生"不要"抄"**：同一集合多处各写一遍，加成员必漏一处、症状还**静默**（源码端漏 ⇒ 写得进去读不出来；DOM 端漏 ⇒ 降回默认值）⇒ 定一份事实源，其余用 `Object.keys` / 反转 / 拼正则派生。
- ⚠️ **高频事件（mousemove / selectionchange / input）里不许有 O(全文) 的活**（`sourceSpy` 进 `selectionchange` 后每次解析全文 ⇒ 打字卡顿）。
- ⚠️ **淡色不要叠加**：`--text-muted` 对白底 5.01:1，再乘 `opacity:.5` ⇒ 2.00:1 = **隐形**（看着像"功能没生效"）。要更淡就换更淡的**令牌**。对比度是**算**的。
- ⚠️ **实底上的字取"面阶那一端"**（`--bg-card`：亮=白、暗=深），**不要写死 `#fff`**：暗色下语义色全换浅档，白字只剩 1.6:1。
- macOS BSD `grep` **不支持 `\|`** ⇒ 多关键词换别的方式（空结果会被误当成"已清干净"）。

### 🖥 原文那一屏 `项目-文档原文-index.html`
- **应用内的「单独一页」**；**读**态 `.rd-*`、**写**态 `.ed-*`。**读**：无卡片头/计数/动作排；正文限宽 **768**；文档名只出现一次；左栏是**本篇目录**（**从块里推**，收 h1~h3）。
- ⚠️ **原文从哪来**：只存索引 ⇒ 要能读就**必须先有副本**（`POOL.documents[i].body`，块列表）；有副本就必须说清"它不是权威"（页头右端**一直**有「在 <来源> 里打开」+ "只读副本、改动不回流"）。没副本的走"外链"，空态**自己解释为什么**。
- ⚠️ **存与渲染只认块**（`rdBlockHtml`）；`mdOfBlocks`/`mdOfSource` 是编辑面进出的**双向转换器**；**预览 = `mdOfSource(源码)` → 同一支 `rdBlockHtml`**。**保存即规范化**。**加一类块/行内写法要同时改四处**（`mdOfBlocks`/`mdOfSource`/`rdBlockHtml`/`rdInline`）—— 少一处 = "写得进去、读不出来"。
- ⚠️ **`mdOfBlocks` 的分段规则必须与 `mdOfSource` 的连续行规则对齐**：末尾是 `out.join('\n\n')` ⇒ **一个块必须一次 push 完整段**。实锤：表格原来按行分多次 push ⇒ 行间被插空行 ⇒ 解析回来**每行一张小表**（4 行表 ⇄ 5 张 2 行表），而 `edSave` 走 `mdOfSource(md)` ⇒ **保存一次就毁表格**。`ul`/`ol`/`task`/`code` 都是一次 push 多行。
- **行内标记**：`**粗**` `*斜*` `~~删~~` `==高亮==` 反引号码 `[文字](地址)` `![说明](地址)` `<span style="…">`（`rdSpanStyle` 白名单：color/background/font-size/font-family/text-decoration，值各自过正则；**font-family 禁 `"`**）；`<br>`（格内换行）与 **`<sup>` / `<sub>`**（上下标，v8.23）也认 —— 后两个是"markdown 没有对应写法"的那一类，只能存行内 HTML。
  ⚠️ 行内 HTML 必须**在 esc 之前**抽出；已产出的 HTML 进占位符（`hold` **存入即还原**）；顺序 = span → code → br → sup/sub → 粗/删/高亮 → `*` 最后（`*` 留最后是因为 `**粗**` 里也有 `*`）。
  ⚠️ **占位符表（`keep`）是整棵递归树共享的一份**，不是每层一份（`rdInlineRun`）。实锤：`<sup><span style="…">b</span></sup>` 这种"span 先抽、sup 后抽"的顺序里，内层递归会碰到**外层已存进去的占位符** —— 各持一份 keep 就会按下标查到空表 ⇒ 写出字面的 `undefined`（上标 + 颜色混用必现）。体检工具里有 5 条嵌套样本专测它。
- **块 16 类**：h1~h6/p/ul/ol/task/quote/code/table/note/hr/img/video + `p.al`（`<div style="text-align:…">`，只作用正文段落）；视频 `@[video](地址)`；列表**缩进 = 层级**（两个空格一层，存在项文本里）；图/视频**占位卡**（原型不联网取图）。`note` 从三档扩到**五档**（见上「提示块五档」那条）。
- **段落级样式 = `<div style="…">` 包整行**（v8.28 起有两项：`text-align` 与 `line-height`，可同时出现）。
  出入两头共用一支白名单 **`rdParaStyle` / `rdParaStyleStr`**（与行内那支 `rdSpanStyle` 是**两张表，别混**）。
  ⚠️ 渲染端**写行内 style**（不是 class）、序列化端**读 `style` 属性**并过同一支白名单 ——
     一端用 class、另一端读 style 就会"设了、存下来没了"（对齐当年正是这个毛病）。
     所以**不为它们写 CSS 规则**（写了就是"同一个东西两处表达"）。
  ⚠️ 改段落样式要**两项互相保留**：`edSetPara(ta, key, val)` 先把这一行拆成 al/lh 再改一个放回另一个
     （原来那版用一条写死 `text-align:` 的正则单独剥，加了行高之后它就匹配不上、把整个 div 连对齐一起吃掉）。
  ⚠️ 行高只作用**正文段落**（与对齐同判据：标题/列表/引用/代码块各有各的排版，塞进去是假承诺）。
- **有序列表的编号样式**（v8.28）：`<ol type="a|cn|multi">` 与 `</ol>` **各占一行**把列表包起来 ——
  照**代码块 fence** 那条路子（有配对标记，才谈得上"这一整块的属性"）。默认档**不包**（裸行就是 markdown 本来的样子）。
  ⚠️ **标号的位置用 `text-indent` 让出首行，不要用绝对定位**（v8.32 改）：
  `ol { padding-left }` 把内容推右、`li { padding-left + text-indent:-N }` 把**第一行**拉回 ——
  第一行的第一个盒就是那个 `::before`，正好落在留白里。绝对定位那套（`left:0` + `transform:translateX(-100%)`）
  要**估自己的宽度**，而标号宽度是可变的（`1.` / `10.` / `1.2.1.`）⇒ 出过一次事（用户截图里两个标号叠着）。
  ⚠️ `list-style` / `list-style-type` / `list-style-image` **三条一起写**：只要有一条被盖掉，
  浏览器自带的 marker 就会和我们的标号**叠在一起**（"连续点会重叠"就是这个）。
  ⚠️ **取消列表 = 只取消"选中的那一项"（默认 = 光标所在项）**（v8.33）：列表拆成
  「前段列表 / 裸行 / 后段列表」，**后段写 `start` 续号** —— 被取消的行**留在原位**，
  后面的序号接着数（用户：「只取消选中的行，默认当前行，如果是取消的中间的，那后面的序号重写计算」）。
  可视面 `edWysListDrop`（前后两段用 DOM 拆，后段要**当场**写上 `counter-reset`，别等重渲）；
  源码面 `edToggleOl`（两段用**配对行**拆，后段总包 `<ol start="N">`；被取消的行要**剥掉 `N. ` 前缀**
  并丢掉缩进 —— 少这一步就是"点了取消、看着没变"）。
  ⚠️ 不拆的话，裸行夹在中间会把列表**断成两张**（`mdOfSource` 按连续行成块）⇒ 后半段渲染时从 1 重数，
  于是"源码里写着 3.、看着却是 1."。
  ⚠️ **`start` 要两处一起给**：HTML 的 `start` 属性（**编号字面量**用，`mdOfBlocks` / `mdBlockOf` 都从它起算）
  +（有编号样式时）`style="counter-reset:l1 N-1"`（**标号是 CSS counter 画的，不认 `start`**）。
  ⚠️ **列表 → 段落 / 标题 / 引用：一项一块，且只搬每一项的"内容"、不搬 `<li>` 本身**：
  `<li>` 一旦落进 `<p>`（不在 ol/ul 里），浏览器按 `display: list-item` 渲染、标号取 UA 默认的 **disc**
  ⇒ 用户看到的正是「点了列表再点取消，**但是变成了无序列表**」；只搬第一项还会丢内容
  （三项列表挤进同一个 `<p>`）。实现在 `edWysSetBlock`（列表那一支返回**一组**，`nexts`）。
  ① 渲染端写 `data-num`（样式与序列化读**同一个属性**，不另加 class）② 三档全是 `::before` + 自己的计数器
  （`list-style-type` / `::marker` 表达不了「(一)」与「1.2.1.」；而 `::before` **不进 `textContent`** ⇒
  序列化读不到它，正合意 —— 它是"标号"不是内容，与标题左侧那个灰 `#` 同一条判据）。
  ⚠️ 三档共用同一套计数器（l1/l2/l3），只有 `content` 写法不同 ⇒ 换方案不会编号错乱；
     `multi` 档的 `padding-left` 要单独加到 46px（`1.2.1.` 往左伸，22px 放不下）。
- ⚠️ **选值型下拉的语义 = "把这一段变成这样"，不是"只对已经是这样的块生效"**（v8.29，用户实测撞上）：
  光标在正文段落里点「编号样式」时，**先把它变成有序列表**再套档位（可视面 `edWysListNum` 里先
  `edWysSetBlock('ol', false)`；源码面 `edSetListNum` 里先 `edPrefixLines(ta,'ol')`）。
  原来只回一句「编号样式只对有序列表有效」⇒ 用户读成"**这个按钮点不动**"（并截图来问为什么）。
  判据：**按钮的名字说的是"结果"，不是"前提"** —— 要先看前提、再先切一次别的按钮，就不叫能点。
- ⚠️ **有些块不许换**（`edWysSetBlock` 开头的白名单，只放 `p|h1~h6|ul|ol|blockquote`）：
  表格 / 代码卡（块根 `div.rd-code`）/ 图 / 分割线 / 提示卡 —— 它们整块就是"一张卡"，
  换掉等于把结构拆了（实锤路径：光标在表格里点编号样式 ⇒ 拿 `table` 去 `replaceChild`，整张表连同内容一起没）。
- ⚠️ **列表项的层级永远要有一个值**（`rd-ind0` 也是值，**"不写"不等于"第 0 层"**）——
  层级的**唯一**表达是 `class="rd-indN"`，`edWysIndentOf` 与编号样式那套 CSS 都按它匹配。
  两头都要显式写：**新造的**（`edWysListFrom` 从正文段落转过来时）与**退到第 0 层的**（`edWysIndent` 里
  `at === 0` 也要写 `rd-ind0`，老写法 `if (at)` 会把 class 摘空）。
  实锤：新列表的 li 光秃秃 ⇒ 编号样式的标号**整排消失、只剩 ol 那 22px 内距**
  （`list-style: none` 已经把浏览器默认标号关掉了，我们那套 `::before` 又匹配不上）
  —— 用户原话「为什么**只加了缩进**，有序列表的文字怎么没显示」。
- ⚠️ **有序列表的编号按层级各算各的**（`nextOlNum(cnt, lv)`，`mdOfBlocks` 与 `mdBlockOf` 共用）：
  markdown 里嵌套列表的编号是"**每层从 1 开始**"，层级靠缩进表达。拿数组下标/children 下标当编号，
  层级一交错就把"一级第 2 项"写成 `4.`（加编号样式时才露出来的**既有 bug**）。
- **外形照语雀**：`.ed-paper` 只剩 `max-width:768`；**工具条搬出纸外**做成页头下**贴边横条**（吸 `top:59px`）；正文框**裸化**；**字数搬左下角** `.rd-words`；阅读态一并去卡。
- **工具条分块（v8.27）**：28 个控件切成 **8 组 / 7 条竖线**，判据是**操作属性**而不是"看着差不多":
  ① 历史（撤销重做）② 格式处理（格式刷 / 清除格式）③ 块级取值（段落样式 / 字号）
  ④ **切换型**行内标记（B I S U + 更多文本样式）⑤ **取值型**行内样式（字体 / 颜色 / 高亮）
  ⑥ 对齐 ⑦ 列表族（有序 / 无序 / 缩进进出一对 / 待办）⑧ 插入族（链接 图片 视频 分割线 引用 代码块 表格 提示）。
  ⚠️ ④⑤ 必须分开：**"按一下加一个开关"与"选一个值施加上去"是两种操作属性**（语雀那一排也是分开的）。
  ⚠️ **"分块"要三条一起，少一条都没有块**：
  ① **看得见** —— 原用 `--line-strong`(#D2DAE7)，对工具条底(--bg-page #ECF0F7) 只有 **1.23:1**，
     1px 宽等于没画（用户原话「分块，不同的操作属性之间竖线隔开」就说的是这个）。改用
     `--text-muted` 叠 **0.62** 透明度 ≈ **2.3:1**。
     ⚠️ 这里的 opacity **不是**"淡色叠加"那条坑 —— 那条说的是**文字**（`--text-muted` 本身 4.5:1，
        再乘 0.5 掉到 2:1 就读不出来了）；这是一条**装饰线**，只要求"看得出来"。
  ② **够高** —— 20px（按钮 30 的 2/3）；矮线读成"逗号"，不像分栏。
  ③ **组间比组内松** —— `margin: 0 8px` ⇒ 组间实距 21px、组内只有 2px（十倍差）。
     只加线不留白 = 在一堆挤着的东西中间插了根针。
- **带箭头的下拉 = 主按钮 + 箭头两半**（v8.28：有序列表 / 缩进 / 行高；v8.35 加：提示；`edSplitHtml`）。
  ⚠️ 是**两个真 `<button>`**：点**图标**干默认的活（切有序列表 / 减少缩进 / 行高回默认 / 插一条提醒），
  点**箭头**才展开菜单。做成"点哪都弹菜单"等于把默认动作藏起来。
  ⚠️ 顺序照用户截图：**无序（无箭头）→ 有序▼ → 缩进▼ → 行高▼ → 待办**；
  ⚠️ 无序那颗**不该有箭头**（它没有"样式"可选，装个箭头就是假承诺）。
  ⚠️ 箭头那颗用 `data-ed-pop`（同颜色/高亮那两颗的开关逻辑），菜单项用 `data-ed-tool`（动作）
  或 `data-ed-pop-set`（选值）—— **两条委托都已经在跑，下拉里一行点击处理都不写**。
  ⚠️ **主按钮"有没有当前档"决定箭头亮不亮**：行高 / 编号有当前值 ⇒ 非默认时那颗亮（菜单收着
  时唯一看得出"这里动过"的地方）；缩进 / 提示是**纯动作**（没有"当前值"）⇒ 永不带 `is-on`。
  ⚠️ 菜单里的"当前档"（行高打勾 / 编号卡片描边）读的是**光标所在那一段**（`edWysBlock()`），
  不是"上一次点了哪一项"——与那五颗行内标记**同一条判据**，所以放在 `edSyncMarks` 里一起同步。
  ⚠️ 判"选中"的选择器要**限定在菜单内**（`#edPop-ind .ed-pop-menu [data-ed-tool]`）：
  主按钮自己也带 `data-ed-tool`，不限定就会多数一个。
  · ⚠️ 工具条是 `#docSource` 的**直接子节点**、与 `.ed-layout` 平级 ⇒ 目录编辑态停靠位靠 **`.ed-toolbar + .ed-layout .rd-toc`** 写。**工具条高度实测写进 `--ed-tb`**（`edSyncToolbarH`），`top`/`max-height`/正文框 `min-height` **一起读它**（控件两排、窄视口必折行）。
- **提示块五档（v8.35）**：`提醒(info·蓝) / 建议(tip·绿) / 重要(imp·紫) / 警告(danger·红) / 注意(warn·橙)`。
  **v8.36 起渲染成一张「告警卡」**（照用户给的截图）：左侧 **4px 实色条** + 整圈细边（档色 34%）+
  极淡同色底（档色 7% 压进卡面，**不新造令牌**）；卡内两行 —— 上一行 **图标 + 档名**、下一行正文。
  ⚠️ 档色收成一支**局部变量 `--note-c`**（在 `.rd-note.is-*` 五条里各指一个语义令牌）：
    边框 / 色条 / 标签三处只写一遍色，加一档漏一处就是"边框紫的、标签蓝的"。
  ⚠️ **档色只落在那三处**，正文一律 `--text-primary` —— 整块染成档色（老样子）长正文读起来发飘。

  ⚠️ `mdBlockOf` 取正文**只认 `.rd-note-body`**（老写法 `querySelector('span')` 在新结构下落空，

  ⚠️ **卡里 Enter = 换行（插 `<br>`）**，不是拆块（与"表格格里换行"同一条判据）：
    不接管的话浏览器会在卡里自造一层 `<div>`，而序列化只认那一段 ⇒ 多出来的层**悄悄丢掉**。
  ⚠️ 图标映射 `RD_NOTE_ICO`（**与 `RD_NOTE` 同序同 key，但不合并**：一个管"叫什么"、

    五枚 = 圆圈 i / 灯泡 / 圆角方块感叹号 / 三角感叹号 / 圆圈感叹号（后三枚是 v8.36 新画的，
    都只有 2~3 个元素、撑满网格 —— 要缩到 15px 显示）。
  ⚠️ **唯一事实源 = `RD_NOTE`**（中文名 + **声明顺序即菜单顺序**），另外三份清单全从它派生：
  ① `MD_NOTE_KEY`（反转中文名 → key）② `MD_NOTE_RE`（源码认 `> [!…]`，**正则由键拼**）
  ③ `NOTE_CLS_RE`（`mdBlockOf` 从类名读回档位，**正则由键拼**）。
  **加档位只改 `RD_NOTE` 一行** —— 这三份早期是各写一遍的，漏一处就是一种静默失效：
  源码端漏 ⇒ `[!重要]` 读成普通引用（"存得进去、读不出来"）；DOM 端漏 ⇒ `is-imp` **降回默认档**
  （页面仍是一个色块，只有再打开才发现"我标的是警告、它说是提醒"）。
  ⚠️ 两档"警"字辈最易写反：`warn` 是**橙**（要留意）、`danger` 是**红**（有风险）。
  ⚠️ **换档位名 = 换 markdown 存法**（`[!提醒]` 这些字面）⇒ 旧文档里的旧标记会读不出来；
  示例数据里的 `kind` 也要跟着改，漏掉的那条会渲染成**字面的 undefined 标签**。
  ⚠️ 菜单项带 `data-ed-pop-set="note:档位"`（走**选值型**那条委托 → `edApplyVal`）——
  用 `data-ed-tool` 塞不下档位。左边那颗**色点**读同一档令牌，hover 时整项上该档**实底**、

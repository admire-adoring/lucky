与「笔记」的边界
判据：有没有外部的、能被读完的原始件
  • 有外部原件（书 / 课程 / 文档 / 视频 / 文章 URL）⇒ 资料，状态是「读到哪」，有终态
  • 是我自己组织的一段理解 ⇒ 笔记，没有进度，只有成熟度
  • 剪藏必须拆两条：原件进资料、我的那段批注进笔记，用 source 互相指 —— 合成一条就算不出"读完没读完"
  • 笔记升级成主题的最终答案后归「知识库」模块（本系统自用、不对外发布，因此没有「输出」分区）

卡片池的归属
一张卡只有一个家
  • 最小单位 = 一张卡（问 → 答，能翻面自评）；面试题与笔记生成的卡都在这里，按「来源」筛
  • 「笔记」里不再有闪卡：卡片归本分区，笔记只放加工过程与成品
  • 需要动手、产物是代码或图的 → 归「练习」（判据：有没有产物，不是有没有标准答案）
  • 一次练习可以关联多张卡（多对多，不算重复）；到期排程统一在「复习」，本分区只管全集与掌握度

为什么这里没有「输出」
个人自用 · 不面向发布
  • 「输出」是按"对外发布"设计的，它的独有字段是渠道 / 发布日 / 反馈 —— 自用系统里一个都用不上
  • 它真正有价值的那部分（把学会的东西整理成讲得通的成品）由本分区的主题级承担
  • "讲一遍检验真懂"这件事已经有家：「题库」的卡 + 「练习」的白板口述
  • 需要拿去给人看的凭证（开源项目）归顶层「项目」模块，不占学习模块的分区

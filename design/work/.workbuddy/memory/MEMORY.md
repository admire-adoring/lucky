## 材质与颜色
- 面阶四档：页 < 区块 `--bg-subtle` < 悬停 `--bg-hover` < 卡面 `--bg-card`；层次 = 明度差 + 1px 实描边 + **两段式小阴影**。浅 `#F4F5F7/#F7F8FA/#E9ECF1/#FFFFFF`，深 `#0A0F1C/#131A2A/#1E2840/#171F32`。
- 强调色三档：`--m-main` 只做图形(3:1)；`--m-ink = color-mix(--m-main 66%, --text-primary)` 做文字；主色实底上的前景（文字 + 图标 + 计数胶囊）一律 `--ink-on-accent`（浅白 / 深 `#0B1220`）。深色只覆写这两个。
- 薄染混**具体面令牌**（`--bg-card` / `--bg-topbar`），不混 `transparent`。
- 描边两档：`--border-subtle` 只分隔相邻区域；输入框/勾选框的形只靠那条边 ⇒ `--border-field` ≥3:1（浅 `#7F899B` / 深 `rgba(255,255,255,.36)`）。
- 选中态不能只靠底色差（白药丸压灰轨道 1.08:1 = 不可见）⇒ 给形状线索（实心/空心圆点、勾形）。**判据：遮住颜色只留明度，还看得出选中的是哪个吗？**
- 面与面靠底色差、不靠线；同色才用线。折行正文必须留行间线，单行短行可不留。
- 文字：浅 secondary `#4A5A72` / muted `#5B6A82`；深 `#94A3B8` / `#8695AB`。带底色 chip 与卡片标题用 secondary。深色下"亮底 + 白字"必不达标 ⇒ 翻深字。`input::placeholder` 要显式写色。
- 图标一律内联 SVG（同 16 网格 / 1.6 描边 / `currentColor`），路径只留一份（`ICON` + `data-ico`/`svgIcon`）。三条硬约束：① 每个容器必须有显式 `color`（`<button>` 不吃继承）；② 缓存记的是"灌的是哪一个"；③ 开关类图标随状态换形状，并断言冷启动。
- 新页面取哪套材质**看兄弟页**（运维 index 仍毛玻璃，日志/部署已纯色）⇒ 新增运维子页走部署页那套。动笔前先比各页 `:root` 令牌。

## 信息架构
- 多种查看方式先拆正交维度：**这两个选项能同时成立吗？** 能 ⇒ 两控件；不能 ⇒ 一分段；都不是 ⇒ tab。
- "前端必须管取什么 / 取了什么 / 还没取什么" = 需同时知道服务端与手上有什么 ⇒ 答案是两者的差。
- 先问「这个值用户和服务端谁知道」再决定进不进表单：只有机器知道的进"检查结果"，只有人知道的才进表单。判据：① 写了"以机器实际值为准"的字段不该存在；② 不填也能提交且无第二个消费者的值不该占必答交互。
- **同一份统计必须收敛成一个 `sync()`**（一处刷新、四处同步；增/删/撤销/初始化都调）。写死的状态色要改成状态类驱动。
- **一条横带 / 列表项只回答一个问题**；同一行混多种性质会平均掉重点 ⇒ 先分性质再排，组距 > 项距。
- 分组不只是分类，是缩写的许可证；计数分两级（组头汇总 + 项级红点）。分组列表表示已统一（日志/部署同套），分组维度从数据现算。
- 「归类」给"选"不给"填"（3~5 项用胶囊）；兜底组永远排最后 → 技能 `inline-row-actions` §五·五。
- 界面能自证的不要再配解释（用户已删四处）；解释只放 `?` 气泡。
- 状态行只说"现在正在发生什么"；低频动作无框文字钮 hover 才出，长驻状态常驻可见。
- 行内动作栏隐藏必须 `visibility:hidden`（不能只 `opacity:0`）；"常驻显示"那两档要同时放开 opacity 与 visibility。
- `margin-left:auto` 前提是一行放得下；主体内容色阶不能低于元数据；彩色徽标 `justify-self:start`；状态码只给异常着色。
- 某块"不好看"先怀疑内容量。

- **值可能有"很多个"的字段，别塞进固定列网格**：一台机器上跑几个服务就有几个端口 ⇒ 这类字段跨满整行（`grid-column: 1 / -1`）+ 一排胶囊、满了自动换行；只有"单值"字段才配 3 列网格（`detail-item.wide` / `port-chips` / `port-chip` 已落在运维页）。
- **详情面板：字段区（`detail-grid`）只放"不用连也能知道"的事**（地址 / 操作系统 / 端口 / 数据库 / 备份策略 = 配置项与稳定身份）；规格、运行时长、版本、提交、部署方式、健康检查都要连上才读得到 ⇒ 不进字段区。判据一句话：**"这个值，没连上的时候存在吗？"** 同一个动作在两个地方有入口时也只留一个（信息面板的「编辑」按钮删掉，编辑只从行内动作栏进）。
- **同一个状态被两个窗口同时表达 ⇒ localStorage + `storage` 事件（双向同步）**：键口径 `<域>:<对象>`（`ops-term:prod-web-01`），每侧都是「初始化读一遍 + 监听 `storage`」，键不存在 = 默认态。三条必踩：① `storage` 只在**别的**窗口改键时触发 ⇒ **本窗口自己改完必须自己刷一遍 UI**；② 两处都能改这个状态时，另一侧也得监听，否则会出现"卡片说已连接、终端说未连接"两套说法；③ **先定"这个状态属于谁"** —— 属于"机器"的就不能绑在窗口生命周期上（连接了就不因关掉终端窗口而断开，`beforeunload` 不删键）。**默认态要选"还没发生过的那个"**：SSH 得按「连接」才建立 ⇒ 服务器卡片默认「未连接」。

## 页面骨架
- 项目详情各 Tab：`hero-mini` → `tabs-wrap`(sticky) → 内容。
- 运维「新建」类 = 整页表单（`…-添加服务器.html`）：`form-layout`（表单卡组包白卡 `.panel`，组内 `--bg-subtle` 分卡）+ 侧轨三卡；底部动作行 `sticky bottom:0`；连接检查各行独立状态，地址一变即作废。同一页承担编辑（`?host=`）。
- 「提权」是登录身份的第二个子块：`su -` 的密码属目标账户；登录用户 root 时提权免认证 ⇒ 密码行收起；同一判据同时驱动卡内徽标 / 检查行 / 侧轨预览（`escFree/escNeedPwd/escWillPause`）→ 技能 `flow-waiting-input-step`。
- 操作型子页（日志 / 部署）从运维页详情面板以独立窗口开：`<a class="sd-tab ext" href="页.html?host=<机器>#win">`，被拦时兜底 `location.href`。**点了就开窗 ⇒ 页内不许再留同名 pane。**

## 布局与内容量
- 横跨整页的第一条带，左右沿 = 侧栏左沿 / 正文右沿 ⇒ 顶栏不写 `max-width`。
- 页头两行（标题 + 动作 / 面包屑 + 副标题）；面包屑只给上级，末段交给大标题。
- 主内容 ≥1200px 拆「主列 + 侧轨」；内容轴收口用 `min(上限, 100% − 2×留白)`，不写死 `max-width`（先算生效阈值）。
- 已知项数用 `repeat(N, minmax(0,1fr))`，窄屏要显式收口；两个控件等高别写死 px（`align-self:stretch`）。
- 纵向填充先怀疑内容量。

## 强制约定（2026-09-26 用户明示，永久生效）
- 不做截图/渲染级验收（不启无头浏览器、不截图）；不加"实现说明/改动清单"；不写不跑任何测试（含冒烟脚本）。
  连带禁用 `html-ds-delivery-verify`、`static-ui-prototype-gates`。边界：只约束"验证/测试/附加解释"，不放松交付质量。
- 自检只走**静态探针**（九条）：① CSS 大括号配平；② `var(--x)` ↔ `--x:` 双向差集（**只查裸 `var(--x)`** ——
  `var(--x, 兜底)` 是显式声明"可以没有定义"）；③ `<body>`→`<script>` 逐行累计 div 深度（终值 0、中途不为负）
  + 块级标签开合数；④ 标记的类 vs CSS/JS 拼串的类双向差集；⑤ JS 声明没被块注释吞掉；
  ⑥ **标记区 id 不许重复**（`getElementById` 只拿第一份 ⇒ "点了没反应"）；⑦ 渐变的归属（只准长在"物件"上，
  不许长在"面"上）；⑧ **裸标识符必须先声明**（读未声明的名字是**合法语法** ⇒ 前面七条全都不报，
  只在运行到那一行抛 ReferenceError）；⑨ 结构断言（如"终点站数 == 路径条数"）。
- ⑧ 的实例：`applyFilter()` 里 `total` 漏了 `const` ⇒ **筛选看着完全正常**，坏掉的只有两个空态。
  写剥离器时**必须连正则字面量一起认**，且 `const a = 1, b = 2;` 的**多个 declarator 都要收**（否则探针自己误报）。
- 探针写法（含模板串假阳性的两条修法）见 `sibling-page-visual-port` §六。

## 材质与颜色
- 面阶四档：页 < `--bg-subtle` < `--bg-hover` < `--bg-card`；层次 = 明度差 + 1px 实描边 + 两段式小阴影。
  浅 `#F4F5F7/#F7F8FA/#E9ECF1/#FFFFFF`，深 `#0A0F1C/#131A2A/#1E2840/#171F32`。
- 强调色三档：`--m-main` 只做图形（3:1）；`--m-ink` 做常驻文字（白卡 55% ≈6.0:1，**66% 只 ≈3.5:1 不达标**）；
  `--m-fill` 做实底；实底前景一律 `--ink-on-accent`。深色只覆写 main/ink。同一支色分图形档与文字档；
  判据：这是**唯一线索**吗？是 ⇒ 必须 ≥3:1（亮绿 `#10B981` 压白 2.54 ⇒ 当焦点环不够）。薄染混**具体面令牌**，不混 `transparent`。
- **描边两档都只够"分隔"**：`--border-subtle`（7% 黑）分隔相邻区域；**要做成"形状"**（输入框/勾选框/纹理线）
  **它不够** ⇒ 换 `--border-strong`（13% 黑）或 `--border-field` ≥3:1（浅 `#7F899B` / 深 `rgba(255,255,255,.36)`）。
- 选中态不能只靠底色差（白药丸压灰轨道 1.08:1）⇒ 给形状线索。判据：遮住颜色只留明度，还看得出选中的是哪个吗？
- 面与面靠底色差、不靠线；同色才用线。**sticky 条的底色 = 它压着的那个面**；**一个令牌不当三件事**。
- **给一个按钮固定底色前，先数它压在几种面上**：行内按钮压在"未悬停的行"与"悬停的行"两种面上 ⇒
  一个固定底色必然在一种面上撞成一样、在另一种面上变成"比背景还浅的洞" ⇒ 这种按钮**悬停只改字色**。
- 文字：浅 secondary `#4A5A72` / muted `#5B6A82`；深 `#94A3B8` / `#8695AB`。深色下"亮底+白字"必不达标 ⇒ 翻深字。
- **不搬"以后可能用得上"的令牌/组件**：代价不是字节，是下一轮 review 要判它是否生效。原地留一句"某某没搬 + 为什么"。

## 图标一套制（技能 `icon-system-consolidation`）
- 全页一种网格（24 网格 / `stroke-width: 2` / `currentColor`），路径只留一张表（`ICON` + `svgIcon`/`paintIcons`/`setIcon`）。
  静态 markup 用 `<span data-ico="名" data-ico-size="16">` + 收尾一次 `paintIcons(document)`；JS 拼串直接 `svgIcon()`。
- 四条判据：① 容器必须有显式 color（`<button>` 不吃继承）；② 缓存记"灌的是哪一个"；③ 开关类图标**随状态换形状**；
  ④ 灌 svg 必须 `innerHTML`。`[data-ico]` 基线规则写在各组件**之前**；24 网格缩到 13~16px ⇒ 描边写 **2**。

## 导航壳（v5）· 详见技能 `module-prototype-nav-mount`
- 来源 `design/index/导航-v5.html`，只截「导航段」。三个跨页口径：① 圆盘 = 内容分区，点非当前项只切内容、
  点当前项或中心门才下钻；② 一级模块只有本模块可进，其余只提示；③ 页头只放路径。
- ⚠️ 圆盘"切内容"两种实现，挂载前先定（判据 = 分区**能不能同时成立**）：能 ⇒ 同页并列、全可见，圆盘只做
  「定位 + 滚动同步」（h1 写**页面**名）；不能 ⇒ 互斥 `display` 切换。判错代价大。
- **分区也可以是"数据里现算出来的那几组"**（服务器页 = 各项目 / 详情页 = 本页四段）：`SECTIONS`/`MODULES`/命令面板
  条目同源现算。写死常量就会在删空之后留一格点进去什么都没有。
- 壳令牌 = `--bg-float` + 薄染四档；单模块挂载要删掉 v5 的 `applyColors()`。三级要么真、要么不承诺。
- `activatePanel(key)` = 滚到它 + 更新当前项 + 切 `data-*`；`spy()` 跟 `.main` 同步（`.main` 才是滚动容器，
  程序滚动期间 `spyLock` 挡回声）。侧栏的槽**数**要看有没有第二处表达（槽里放 KPI 而顶部已有仪表条 ⇒ 只留一侧）。

## 信息架构
- 多种查看方式先拆正交维度：能同时成立吗？能 ⇒ 两控件；不能 ⇒ 一分段；都不是 ⇒ tab。
  **反过来也成立**：形态已经唯一时别再架一个只有一个选项的分段（那是噪声）；
  删掉一种形态要按「连带面清单」走 —— 见 `MEMORY-其它页面.md` §「删掉一种视图 / 一种形态」。
- **同一份数据多视角：全留 DOM、切换只改 `hidden`（零重渲）**。代价是 N 份表达 ⇒ **状态一次刷全部**、
  定位按当前视角取容器、可见性判据一律 `closest('[hidden]')`、给筛选/定位立**契约属性**（`[data-view-item]`/`[data-view-group]`）。
- **两维筛选：筛的永远是"另一个维度"** —— 按什么分组就别筛那个维度；切维度时另一维**归零**；筛到 0 条要有**退路**；
  筛选与导航说的是同一维度时**必须是同一个状态**（否则 `scrollIntoView` 落在 `display:none` 上 = 死点击）。
- **多对多（一个实体属于多个分组）时，分组视图里它在每一组各出现一次**。三条连带：① 组内计数重复计入共享项，
  页面级计数数的是**唯一**数量 —— 两个分母不同，别互验、别拿它当筛选分母；② "多值归属"**不许塞进单值位置**
  （副标题 / 主字段 / `project:` 字符串），只能落到能换行的列表里；③ 判据只写一处（`servesProject()`），
  分组 / 筛选 / 计数 / 胶囊全走它。
- **过滤只在已渲染 DOM 上改 `el.hidden`、不重渲**（展开态/焦点/滚动全留）⇒ 条件渲染的元素**必须总是渲染**。
  ⚠️ `[hidden]` 只自带 `display:none` ⇒ **作者样式里写了 `display` 的元素要先补 `[hidden]{display:none}`**。
- **贴内容的计数跟筛选走**（卡徽标 / 组头）；**分区级计数不跟**（Tab / 圆盘 / 侧栏）。**同一份统计收敛成一个 `sync()`**；
  ⚠️ 对空数据集取值必须有护栏（`sort()[0]` 为空就抛 ⇒ 整条 sync 断在中间，后面每处停在旧值且不报错）。
- **同一个数字只在一处表达**；**会变的值不能写死在常量表里**（现算 + 收尾 `syncChrome(false)`）；⚠️ 删元素后必回头删 JS 引用。
  筛选器门槛：**它省的是滚动距离不是点击** ⇒ 一屏放得下的清单不配筛选。
- **把一行里的内容搬走之后，回头问"这行还剩几个字"**：只剩 2~4 个字的那行就是"空壳行"（判词「直接为空，不显示了」）。
  解法不是往那行塞别的东西，而是**整行去掉 + 身份改成形状**（文字搬进 `title`/浮层，且必须有第二个家）。
- **一条横带/列表项只回答一个问题**：先分性质再排，**组距 > 项距**；计数分两级；分组维度从数据现算；
  「归类」给"选"不给"填"；兜底组排最后。**同一层级的"归类"，一张卡上只许出现一处**（判词「两处在说同一件事」；
  判据是**层级**不是数量）—— 卡面说过"这机器干什么"，卡脚就该换成"有多少 / 点开看"。
- **列表行分层：第一行放会变的状态，第二行放不变的身份**；"要连上才读得到"的值连卡片也不该进；
  **一条列表里颜色只承载一种语义**（颜色给状态，形状给身份）；分组标题说过的事行上不再重复。
- **唯一的高频动作不能和低频动作一起藏在 hover 里**；若它同时是某长驻状态的表达就**合成一个元素**。
  行内色条别用 `border-left`（内容右移 2px）⇒ `box-shadow: inset`。
- **"整行可点 + 行尾另有动作"时：整行是一枚真 `<button>`，那些动作必须落在它外面。**
  两个理由都是结构性的：角色按钮里套按钮非法；`<div role="button" tabindex="0">` **按 Enter 什么都不发生**
  （它只活在鼠标点击那一句 `onclick` 上）。落在外面的附带好处：不用 `stopPropagation`。
- **折叠：默认全展开**（收起是读者的动作）；**收起后必须补一句"还藏着几条"**（只数叶子），
  否则"收起来"就等于"信息丢了"；只切一个类、**不重建标记**（重建会丢别处的收起态/焦点/滚动）；
  `aria-expanded` 挂真按钮，别顺手套 `role="tree"`（那要配完整键盘模型）。
- 卡片头是动作入口的唯一去处；**值可能"很多个"的字段别塞固定列网格** ⇒ 跨满整行 + 胶囊换行。
- **分区里放什么，由"它答应回答哪个问题"决定**，不是由"能取到哪些数据"决定。
- **"位置清单"类块：交互 → 分组 → 样式**（点行开抽屉；十几条平铺必先分组；最后才调字号/悬停）。
- **"总览"这一屏的净增量 = 它说了什么别处说不出的话**（卡头计数 vs 上一级 tab、摘要是分区页首屏的第二份 ——
  三处都重复时净增量≈0；唯一不可替代的是**跨分区的那一句**）。⚠️ 与"卡片墙"分开判：卡片墙的前提是每张卡回答**不同**的问题。
- **"太普通" = 一批条目同形、同重、同节奏 ⇒ 读者找不到视觉起点**（读成"设置列表"）。破法**不是**
  加点缀（渐变 / 阴影 / 彩色底 —— 那是给"面"加材质，与"这批条目没有形状"是两件事），
  而是**让每条长成它自己那条数据的形状**：26/36 → 进度条；1 条致命 → 告警三角；
  最近三本文档 → 三根书脊；2 台机器 → 两枚机架；11 月 5 日 → 日期块；3 个平台 → 三枚方块。
  三条配套：① 图形槽**固定宽度 + 右对齐**（否则各行图形宽窄不一，把结论句推得参差）；
  ② 图形**不许超过身份图标那 24px**（超了把那一行撑高 ⇒ 分隔线不等距，像"这行更重要"）；
  ③ 形状必须**从数据来** —— 装饰性图形读第二遍就没有信息，还会把结论句挤小。
  连带：N 条独立浮卡 → **一块面板 + 内部发丝线**（N 张各自带描边阴影的卡会把"一体的 N 个面"
  拆成 N 个平级条目）。
- 按页面的判据（表单字段该不该存在 / 发布记录不许手填 / 两窗口同状态 / 聚合页四问 / 卡头落不同维度 / 异常色）
  见 `MEMORY-其它页面.md` §「按页面的判据」。

## 形态选型：一段的数据是什么形状，它就长成什么样子（2026-09-29 立）
- **表单形态三档**（2026-09-30 立）：判据是**填的时候要不要一边看着清单** —— 要 ⇒ **抽屉**（改严重度时想比一比"还有哪些致命"）；
  不要且 3~4 格 ⇒ 小弹窗；不要且跨三四组 / 带检查预览 ⇒ 整页 `?id=`。⚠️"字段多"**不是**选整页的理由。
  表单自己的三条：**必填只留"这一页存在的理由"**（其余可空 ⇒ 渲染侧必须吃空值）、**系统已知的值只回显不手填**（编号）、
  **封闭集合给胶囊 / 开放集合给 `<input list>` + 现算 datalist**。胶囊的 `data-v` 必须与常量表 key 同源（静态写死就要有断言盯着）。
  层次：抽屉 190 < 弹窗 200 < Toast 300，ESC 从最上面那层退。
- **书** = 有限、可数、有封面（文档）；**抽屉** = 从属的一份、抽出 → 看完推回去（项目 → 该项目的文件位置）；
  **路线图** = 数据里只有层级关系时画拓扑（线路 + 站点，同源干线合并；技能 `path-tree-route-map`）；
  **分组清单** = 数据是"一份有状态流转的申报"时按那个状态分组（Bug：待修复→修复中→待验证→已关闭，
  而且是**环**不是线 —— 已关闭有一条回到待修复的边，行尾那枚按钮就是这条边）。
  ⚠️ 同样是清单，**分组维度必须换**才能和邻居页区分：任务由**日期**驱动（到期了没有），
  Bug 由**状态**驱动（修到哪一步）—— 两页合成的结果就是同一件事说两遍。
  **没有形状的**就老实做成字段读数（概览），别硬套一个物。
- ⚠️ **"地图"必须有方位 / 距离 / 相邻才有意义**：数据里只有层级时画地图 = 编造"这两条路径挨着"，
  与"没有的数字一处都不许出现"是同一条。
- 同族的两个抽屉（项目 / 文件）靠 **z-index 分层（后开的在上面）+ ESC 逐层退**；
  抽屉里的清单**要现算**（一次只开一个，为它预渲 N 份是浪费），但它与"多视角全留 DOM"不冲突 —— 那条针对的是**并存**的视角。

## 页面骨架
- **同族的第 N 页：从上一页的构建脚本『派生』，不重新切一遍壳**。派生完删掉中间脚本，只留
  `<页面>.build-*.py`（可重跑）+ `._seed-*.cjs`（内容生成器）+ `._probe-*.py`（探针）。
  ⚠️ **源页选"最新的那一页同族兄弟"**（它踩坑最少），派生关系不用传递（Bug 页从账户页派，
  而账户页自己是运维页派的）。全套做法见技能 `derive-sibling-section-page`。
  ⚠️ 派生脚本做的是**文本替换** —— **令牌定义与图标 key 长在源页里、运行时才切进来**
  ⇒ 删令牌/换图标那类替换必须写到**目标脚本的运行时**（对切出来的 CSS_SHELL 做 rep）。
  **派生"详情页"时反过来**：从**同模块的兄弟页**派，只换内容区。三步都要断言：① CSS 按"还有没有消费者"
  **删块**（`@media` 要递归进去 —— 外层选择器没有类，整块会留下）；② 主内容整段换（`<main>…</main>`）；
  ③ 脚本**按函数块边界删**。⚠️ **文件头必须一起换**（留源页那一篇会让人以为分区/分工/默认态是那样的）。
  这一路的踩坑（自指断言 / 尾逗号 / 注释污染类名判据 / 删块收尾吃缩进 / `<script>` 字面量带偏锚点 /
  生成器必须叫 `.cjs`）见当日日志与 `.build-server-detail.py` 的注释。

## 布局与内容量（全表在 `MEMORY-其它页面.md` §「布局与内容量」）
- 量出来的四条最通用：**列数按「容器宽度」断不按视口断**；**`grid-auto-rows: 1fr` 会全局拉平**（要"同排等高、排间贴合"用 `auto`）；
  **卡要有页脚 `margin-top: auto` 才有落点**；**`visibility:hidden` 仍占宽度** ⇒ 绝不要"占列 + 隐藏"。
- 量任何"对不齐 / 间距大 / 高低不齐"之前，先数**祖先层数**与**两处 padding**，别急着补 padding 去"追"。
- **透明底上的分组，必须给"线"或"面"，不能只给留白**（2026-09-29 Bug 页返工）：
  相邻两行只差各自的内边距时，读者看到的是"一个长段落"。加间距 + 每行圆角**也不够** ——
  圆角在没有底色时根本看不见 ⇒ 给 `+ .row` 顶上一条 `--border-subtle`（它的用途正是"分隔相邻区域"），
  或给整行一个面阶底色。判据：**"这两段该不该分开"要问它靠什么分开**；
  间距只在"周围本来就有底色差"时才成立。
- **三格并排时字号必须对齐**（同上）：KPI 那种一排三格里有一格换了字体（等宽）就顺带换了字号
  ⇒ 读者会以为"这格不一样重"。换字体可以，字号/字重跟着原档走。
- 定宽度的物（书 96px / 开本 5:7）不随容器变形 ⇒ `repeat(auto-fill, Npx)` 而非 `1fr`。
- 卡片墙、卡头三个东西、超短类名撞车、层次 1.25 比例 —— 例子都在上面那一节。

## 踩坑（高频，全表在 `MEMORY-其它页面.md`）
- **"内容能不能被看见"不许依赖脚本**（预览面板走静态 HTML 视图）：主内容必须是静态标记、JS 只做增强。
  要静态又要与运行期同源 ⇒ 加**内容生成器**（切出页面自己的模板函数跑一遍），不手抄第二份。
  ⚠️ 抽屉 / 浮层那种"默认关着"的容器**不用灌**（看不见，灌了是死的）。
- **块注释不能用 HTML 注释的收尾去结**（`-->`）⇒ 一路吃到下一个收尾符，中间的函数被吞掉，而 `node --check`、
  div 深度、令牌/类名差集**全都通过**。同类：注释里写出块注释收尾符本身会把注释就地截断。
- **`display:none` 的元素 `getBoundingClientRect()` 全是 0** ⇒ "按几何取当前项"的逻辑会把**隐藏项**当命中，
  且按顺序遍历时"最后被藏起来的那个"会赢 ⇒ 先 `closest('[hidden]')` 跳过，兜底取"第一个可见的"。
- **同一份数据有 N 份表达时，id 必须带维度前缀，取元素改走"按关系找"**（`row.nextElementSibling`）。
- **`div` 改 `span` 时，只有写了 `display` 的那几条能活**（原生 `<button>` 里只许放 phrasing content）：
  inline 的 span 上 `margin` / `text-align` / `text-overflow` **全不生效**，表现是"看着差不多、其实没居中也没截断"。
- **flex 项默认 `min-width: auto` ⇒ 不会收缩**：长文本会把整行撑出容器、右侧被切（而不是显示省略号）⇒ 显式 `min-width: 0`。
- ⚠️ **新类名先和「全页既有类」求交集**（判据是**交集**不是差集）：给新组件起名前，拿候选名去和整页已有的
  类名求交集，非白名单的一律改名停构建。**踩过**：路线图容器取名 `.rail`，而导航壳的"收起态图标列"正是 `.rail`
  （`display:none`）⇒ 整段被吃掉；**类名双向差集查不出来**（两边都有定义、两边都有标记）。别用
  `.rail / .line / .path / .node / .item` 这类"通用物件词"给局部组件起名。
  ⚠️ 三处容易漏的第二现场：① **自定义属性同规矩**（`--cols` 与命令面板 `.mega-grid` 撞名，
  那边存列**数**、这边存列**宽表**）；② **"上一版的禁用清单"本身也是既有名** ——
  收尾断言里躺着 `assert 'ov-head' not in HTML` 时，新表头就不能再叫 `.ov-head`
  （而且**连注释里都不能写出那个全名**：`in HTML` 不分标记 / 样式 / 注释）；
  ③ **断言盯"有没有"，别盯"恰好一次"** —— 窄档给同一选择器再写一档尺寸（`.ov-bar { width:34px }`）
  就会把 `count(...) == 1` 打翻；只有"这几处必须同步"才算契约（如表头与行共用的那份列宽变量）。
- **静默失效**：删 CSS 留孤儿声明（拆函数时同样要查"谁还在消费这个类"）；`const` TDZ；对象字面量里的兄弟看不见
  彼此的 `let/const`；**新增的类写在它要覆写的类之前**；**自输入内容拼进 `innerHTML` 不转义**；
  **把一批孩子搬进一层新容器**（如给整行套一枚 `<button>`）⇒ `> .a > .b` 那类**落了旧位置**的子选择器全失效 ——
  CSS 不报错，元素直接不见（判据：改结构后拿"新容器名"去全文搜一遍 `>` 链）。
- **派生页的三个新坑**（2026-09-29 Bug 页）：① 源页把**通用函数放在"内容段"里**（`toggleOpsCard` 长在账户
  抽屉段）⇒ 被一起切走，而本页标记还指着它 = "点了什么都不发生" ⇒ 切段前列出本页引用的全部函数逐个确认；
  ② 基础段里**混着只在源页有消费者的规则**（侧栏 KPI 槽 / `kpi-unit` / `btn-danger` / 输入框描边令牌）
  ⇒ 按选择器前缀整块删（`@media` 递归）；反向：`.badge` 那族**长在源页专属段里** ⇒ Hero 的徽标会变裸文字；
  ③ **重跑构建脚本前先 diff，并且派生脚本的"二次清理"步骤会过时** —— `.build-account.py` 里那段
  `drop_spine()` 本意撤运维页的 `--spine`；等运维页**自己**把声明删干净、只剩注释里提过这个名字，
  判据就退化成"命中注释行"，而"往上 pop 掉紧贴的注释块"把注释**前面**的 `--rc` / `--rc-fg`
  两行真声明一起吃了 ⇒ 症状伪装成"这一页的 HTML 落后于它的脚本"。处置：撤掉那一步，重跑到 `diff = 0`。
- **探针的假阳性**：`<style>` 的注释里也写着 `<span>` / `<button>` 字面量 ⇒ `markup` 要从 `<body>` 起；
  多类名的行（`bug-row is-major is-closed`）用 `([a-z-]+)` 抓不全；对象字面量的 key 不是"读到的名字"；
  `alert/confirm/prompt` 属 window 内置。
- 取段边界要"独占"、夹在不要的大段中间的小块最容易被整段跳过、模板生成时容器与条目分属两层、
  新类名先和"全页既有类"求交集 —— 实例见 `MEMORY-其它页面.md`。

# 专项记忆（日志 / 部署 / 执行 / 表单弹窗 / 侧边导航圆盘）

> 按需读取：只在动这几类页面时打开。总则与跨页判据在 `MEMORY.md`；
> **改任何 HTML/CSS/JS 前，先看文末「结构自检与静默失效」那一节。**
> 侧边导航那节写的是 `导航-v2.html`，但推导值（`radiusFor/iconFor/--dial`）一路沿用到 `导航-v4.html`。

## 分组列表（日志页 / 部署页共用同一套表示）

- **分组是「配置自己的标签」，路径推断只是兜底**（用户口径：「新增的时候加标签，添加到对应的分组中」）。
  契约：`groupFor(c) = c.group || groupFromPath(c.path)` —— **有标签看标签，没标签看路径**。
  两条都要写断言：只测一条，另一条静默失效（本轮就是这样抓到的）。
  表单里标签放在**卡片 ①（名称与分组）的第二行**：左边一枚 `分组` 小标签（52px，与摘要标签列同宽），
  右边四枚单选 chip。**新建时跟着路径自动预选**（填了 `/var/www/…` 就落在「前端资源」），
  但**点过任一枚就以点的那枚为准**（自动只是默认值）；编辑时直接用配置自己的标签。
  保存后 toast 说清落到哪一组（`已创建「X」· 前端资源`），这正是"加标签"要回答的事。
  单选 chip 的选中态靠**一条过 3:1 的靛蓝描边**（4.20/5.82）+ 底色薄染 + 文字提色；
  未选中的 chip 边框是装饰档（1.23/1.67，按 container 单列打印）—— 形由文字标签承担，
  与常用值 chip 同一条判据。**别把未选中的也加深描边**：4 枚都重描边会变成一排框。
- **组框**：`.xxx-group { padding: 3px; border-radius: 14px; background: var(--bg-card-solid);
  box-shadow: inset 0 0 0 1px var(--border-strong); display: grid; grid-template-rows: auto 1fr }`。
  四个刻意的减法（缺一个都会让分组感变弱或整栏变脏）：
  ① **白实底 + 一条描边，不用灰底衬** —— 灰底会和项底、徽标底挤在同一段窄灰阶里；
  ② **描边用 inset box-shadow 而不是 border** —— border 占宽度，会把项挤窄；
  ③ **组头不放延伸线** —— 描边 + 色条 + 计数 + 箭头已经 4 种元素，第 5 种不会增加分组感；
  ④ **组间距只由列表的 `gap` 提供**，组上不再给 margin（两个间距源会叠成两倍）。
- **组头**：色条（3×12px，`color-mix(--dp 45%)`）+ 组名（11px/800）+ `N 条`（`margin-left:auto` 顶右）+ 折叠箭头。
- **缩进做在项的 `padding-left` 上**（`calc(11px + var(--indent))`），不做在容器 padding 上 ——
  否则 hover / 选中的底色从缩进之后才开始，左边缺一段背景、看着像断了一截。
- **折叠用 grid 两行/两列切 `0fr`**（真实过渡），并**延迟 0.22s 切 `visibility:hidden`** ——
  `0fr` 只是"看不见"，Tab 键照样能钻进去。窄屏换"收宽度"（列 `1fr`→`0fr`），同一套逻辑复用；
  展开态要显式 `min-width: min-content`（基础样式的 `min-width:0` 会让 1fr 列被压到 0，
  而写 `auto` 也没用 —— 容器 `overflow:hidden` 时"自动最小尺寸"会直接归零）。
- **当前项所在组要单独标出来**（组数一多，比让用户记住在第几组靠谱）：描边换 `--group-edge-active` +
  组名提到 `--text-primary` + 色条变实色。**只动描边与色条，不动底色** —— 底色留给"当前这一条"。
- **分组是纯展示层**：选中 / 执行 / 编辑全按 `data-id` 找元素，组容器不参与逻辑，且容器上要写
  `role="presentation"`（让 tab 透传上浮，`role="tablist"` 的直接子元素才不是组容器）。
- **分组维度从数据现算、不落字段**：部署页按 `path` 前缀映射到「部署对象」（应用服务 / 前端资源 / 数据库 / 其它），
  于是**改完路径配置就自动归位**，也不会出现"字段记着 A、路径写的是 B"的脏数据。
  空组不渲染（一条都没有的分类标签只是噪音）；配置被删空时整个组消失、全空则回到空态。
  前缀匹配要带边界（`/^\/opt\/app(\/|$)/`）—— 否则 `/opt/appx` 会被误判进「应用服务」。

## 日志 / 部署 / 执行 类界面

- **级别是「日志源」的属性，不是全局 UI 属性**：`access.log`(combined 原文)、`syslog`、WAL 流水都没有级别字段 ⇒
  在 `.log-pane[data-lvl="none"]` 一处声明（不渲染级别列、收起级别筛选器、行强调改用左侧色条）。
  切换日志源必须复位级别状态；动态新增路径**不假设格式**。
- 部署配置 = 「名称」+「传到哪」+「传完执行什么」，仅此三样；**目标服务器不进配置**（`?host=`，页面级一个 `TARGET_HOST`）。
  执行要逐步可见，**中止时进度条停在当前值**（补满 = 假报"传完了"）；`--dp` 上白字只有 4.47:1 ⇒ 实底按钮单独更深一档。
- 执行类页面：步骤列表与原始输出**左右分栏**（输出区可用高 90~130 → 330px）；点某步 → 终端定位并高亮；
  四个刚需：折叠已完成 / 跳到当前步 / 单步重试 / 跳过剩余。**徽标别叠在同色底衬上**（`.step-ok` 自带 4% 绿底 + `--ok-bg` 只剩 4.23:1）。
- **「等待人工输入」是独立第四态**：凡等人敲键盘的命令（`su -`/`sudo`/`ssh`/`read`）一律独立状态（琥珀底 + 强调条 + 计时），
  **进度条停住**，输入框**内联在输出流里**。语义照真实系统：超时即失败、`su` 3 次机会、
  **`sudo` 凭据同一次执行内复用而 `su` 每次重问**；输入后回显掩码并把输入框**从 DOM 移除**；中止必须收掉输入框。
  配置侧只做「识别 + 标注」；图标只用**纯 ASCII**；找「当前步」的选择器必须同时含 `.step-run,.step-wait,.step-err`（漏一处静默失效）。
- **能自动就别让人点**（`autoInfo()` 五档，只识别 + 给建议，**不代改**）：`ready`（已非交互写法）沉默，
  只在 `sudo -n` 那档附一行 sudoers 授权供复制；`rewritable`（`su -c` / `sudo` 无 `-n` / `ssh` 无 BatchMode）
  给出**针对这条命令的建议写法**（等宽 `code`，可直接照抄）；`needsCommand`（`su - user` 没带命令）只说明要补命令；
  `external`（`psql`/`mysql`）只说明要配 `~/.pgpass`；`manual` 交回 `>_` 标记。
  配置级汇总成一个徽标：`全自动`（绿）/ `需输入 N 处`（琥珀）/ `可免密 N 处`（靛蓝）/ `凭据文件 N 处`。
  **`全自动` 要保守**：没有任何人工标记、且没有"可能还要密码"的命令才算 —— 别把"大概能跑"说成全自动
  （自研脚本识别不出来，只能算 ready，tooltip 里要写明"要它自己用 `>_` 标记"）。
  `sudo -n` 那档额外反推一行 sudoers 授权（`<跑部署的用户> ALL=(user) NOPASSWD: <命令>`）供复制，
  **不猜绝对路径**（随发行版变，给错比给裸命令更糟）。
  ⚠/ℹ 的语义固定为「一定会停 / 可能停」，由 `detectAsk().sure` 决定，**不能按"有没有改写建议"来分**。
- **「连接身份」是和「目标服务器」同级的执行上下文**（`?user=`，执行区头部一个 select 可现场切）。
  **root 身份下 `sudo` 免认证、`su - 任意用户` 也不要密码** ⇒ 同一条 `su - deploy`，root 进来就不问输入。
  这条规则**只作用于提权命令**：`ssh` / `psql` 不因为"本机是 root"就免掉对端认证。
  并且 `ask`（用户标的「需人工输入」）在身份已保证免认证时**不该生效** ——
  用 `needsHuman(x)` 统一收口，否则会出现「提示说不会提示 / 徽标说需输入 / 真跑起来停住」三方打架。
  其余免输入的机制：sudo 时间戳缓存（同 tty 15 分钟）、`NOPASSWD` 授权、公钥 ssh + `BatchMode`；
  **`su - user` 没有免密等价物**，同一条 SSH 会话也不能让 `su` 免掉（它认证的是目标用户）。
- **动作行的构成**：按钮常驻，**状态行默认收起**（`setHint('')` → `hidden`），只承接"正在发生的事"
  （执行期报「第 N / 6 步 · 步骤名」+ 转圈；`warn` 态：等输入 / 失败 / 已中止 / 本机找不到绑定文件）。
  **开场不复述"这条配置全自动"那类注解** —— 条数与自动化就绪度都长在摘要徽标上，正文里再说一遍就是噪声。
  行高因此由按钮决定，不随文案长短跳（原来靠 `min-height: 62px` 兜，现在是结构上就不会跳）。
- **编辑 / 删除只留一处入口**：用户 2026-09-25 删掉了右栏头部那对（截图里指向"当前这条"），
  只留左栏列表行内的（对"列表里任意一条"）。右栏头部因此只剩标题
  （再加两条 `标签 52px + 值` 对齐行 —— 两列并排会被长路径折行，且两条的基线会错开）。
- **主按钮的文字与图标必须一起翻**：统一走 `setRunBtn(label, busy)`，busy 时换加载弧 + `disabled`。
  散在各处写 `textContent` 迟早漏掉图标，留下"不忙也在转圈"的按钮。带色光晕（`0 Npx color-mix(--dp-btn…)`）
  是纯色范式明确不要的 ⇒ 换两段中性影。
- **文件有两种来源，但它们是"二选一"**（一次部署只会用一种；并列两张卡会被读成"两条都要走"）：
  ① 从本机选择（`src:'pick'`）；② **绑定本机路径**（`src:'local', path, found`）——
  填一个本机绝对路径 → 自动查有没有 → 有就直接用那份。
  做成**两段控件 + 只渲染选中那一种的面板**；下方清单/总计/第一步名字/开始部署**都只看当前来源**。
  两份**各存一份**（`staged = {pick, local}`，切换不清空——"切过去看一眼再切回来"是常见动作），
  代价是切走的那一边成了隐藏状态 ⇒ **那一边的标签上必须带条数**，否则会出现"上一屏说 3 个文件、
  清单里 0 行"的账对不上。切换的唯一入口是 `switchFileSrc`，三处表现（面板显隐/选中态/条数）
  全在同一处 `renderFiles()` 里刷 —— 状态别有两个来源。`files` 是**函数**（`files()`）不是数组，
  这样"当前来源"只有一个真相源；删项要**就地 splice**，别 `staged[src] = 新数组`（那会让别处的引用成孤儿）。
  三条判据：**每次重画都重查本机**（文件可能刚被删，不能只在绑定时查一次）；
  **未找到的不进总量**（否则是假账）且会**挡住"开始部署"**并指出是哪条（比跑到第三步才失败好）；
  结论行只在"有话要说"时出字，平时留一条同高的空行（打字时整块不跳）。
  「自动查找」在打字时**只报正向命中**，`blur` / 绑定 / 回车才给"找不到"的结论 —— 打字打到一半被红字打断很烦。
  清单里**不再逐行标来源**（只会有当前那一份，分段控件就在上面），绑定文件的完整路径挂在行 `title` 上。
- **输入框的边要单独一档令牌**（`--border-field`）：纯色范式把卡面变实心之后，
  `--border-strong`（1.2:1）只够当装饰性描边；而输入框的形**只靠这条边**被认出来
  （白底压浅灰卡片只有 1.06:1，等于没有形）⇒ 必须 ≥3:1（SC 1.4.11 控件边界）。
  浅 `#7F899B`（对白 3.53）、深 `rgba(255,255,255,.36)`（3.31）。**同一个控件形态共用同一个令牌**：
  `.bind-input` 与 `.modal-input` 一起改 —— 两处文本输入框边不同档，就是新的不一致。
- **「提示行要跟着输入即时更新」**：`input` 事件里 debounce 180ms **只换 `.cmd-note` 一个节点**（`applyNote`）——
  重建整行会丢焦点，而"不更新"会让新敲的命令一直不显示改写建议。

## 表单类弹窗

- **能「选」就不要让人「敲」**：路径、目录这类只有系统自己知道的值，字段标题右侧给一个文字按钮
  （`.field-act`，不占输入框宽度），点开把**弹窗正文换成目录选择器**（同一弹窗换视图，不叠第二层浮层 ——
  正文里飘的下拉会被 `.modal-body{overflow-y:auto}` 裁掉）。
  选择器 = 假目录树 + 面包屑 + 逐级进入 + 筛选框（**条目 ≥10 才出现**，三级目录里放搜索框是给不存在的需求配控件）。
  两端各有一条（日志页选文件、部署页选目录），**差异只有三处**：① **列什么** —— 日志页列文件+目录，
  部署页**只列目录**（用户口径：「目录浏览不需要看到文件」；选的是"传到哪个目录"，文件只会分散注意力）；
  ② 「选中」的落点（选文件 = 点文件名；选目录 = 当前这一层没有条目可点 ⇒ 必须给一条 `pick-bar`：
  当前完整路径 + 「用这个目录」）；③ 路径找不到时的回退（日志页回 `/var/log`，部署页**逐级回退到最长的存在前缀**，
  因为配置是历史留下的）。再要第三个入口就抽"共用目录树 + 可配置的选中语义"，别抄第三遍。
- **列表藏了一半内容时，所有"几项"和筛选条件都要跟着改成按**可见的那部分**算**：部署页只列目录后，
  `children` 总数会把看不见的文件算进去，出现"显示 3 项却只有 2 行"、或"只有 8 个子目录却弹出筛选框"。
  ⇒ 统一走 `dirCount()`。**树里的文件节点保留**（那是机器上的事实、别处可能要用），不参与这个视图而已。
- **列表里"能点但会被拒"的行要给明确反馈**：部署页的目录选择器里文件行不可选，
  用 `aria-disabled` + 无 hover + 点击时 toast 说明原因。**"点了毫无反应"比"被拒并告诉你为什么"差。**
- **换正文视图前要把表单整块摘下来暂存，不能重新生成**：日志页的表单只有两个输入框，
  `showForm(prefill)` 每次重建无损失；部署页有列表编辑器，重建会把**还没保存的输入全清掉**。
  做法：`formView = mBody.querySelector('.form-body')` 摘下来，返回时原样 append 回去 ——
  DOM 一直活着，值/焦点/错误态自然都在。配套：表单要有一个容器类（取 `firstElementChild` 会取到第一张卡片）。
- **换视图时底部按钮要改写，并在 `openConfirm` 里每次复位**（选择器里没有"确认"这一步 ⇒ 只留「返回」），
  否则下一次打开会带着上一次的「返回」。Escape 也要分档：**在选择器里 = 退回表单**，在表单里才关弹窗。
- 字段说明挂在 label 的 `?` 上；气泡必须是 `position: fixed` 的**共享层**、挂在 `.modal-body` 之外
  （body 是 `overflow-y:auto`，贴底会被裁一半）。定位优先级：**弹窗右侧外部** → 锚点下方 → 锚点上方。
- 校验**每字段独立判断并一次全部标出**（别用 `else if` 链），配 `aria-invalid` + `aria-describedby`；
  单行 Enter 提交，多行 ⌘/Ctrl+Enter。
- 多条目字段用**结构化列表**，`max-height` **用视口比例表达，不写死行数**（现为 `min(300px, 42vh)`）+ 内部滚动；
  写死过一次 208，而"行高 40 + 提示行 43"的三行就 179、四行带提示就 260 ⇒ **最后一行底部的提示/建议写法
  被滚动区裁掉了一半**，且所有基于 `textContent / rect` 的断言全绿（文字在 DOM 里、rect 也正常）。
  判据只有命中测试：`elementsFromPoint(元素中心)` 的第一个必须是它自己。矮窗口那条**单独压到 150 的覆盖
  正是元凶**，删掉后矮窗口只多 29px 内部滚动（弹窗底部按钮照旧常驻），比"看不见"划算。
  编辑器内部用**隐藏 input 存 JSON** 当值载体，
  校验/计数/摘要沿用同一套读法（但写回 `CONFIGS` 时要转回数组，见下条）；
  **常用值 chip 灌值必须重建列表 UI**。**不要再加「实时预览 / 汇总」这类自造区块，也不要常驻引导说明段**（用户删过两次）。
- **不代用户改写命令** —— 这条是被用户分两步确认的：先删字段级的「全部改成免密写法」（批量的、不商量就换掉多条），
  同日再删行内的「改成免密写法」（单条的）。**结论：工具只识别 + 给建议，改不改、怎么改由人决定。**
  命令是他亲手写的，工具代它改比"告诉他建议怎么写"更容易出错。
  ⇒ 建议写法的剩余价值只剩"摆在提示行里让他照抄"（`info.to` 渲染成 `<code>`）。
  **这条判据可外推**：凡是"用户亲手写的东西"，工具都不要替他重写，只给参照。
- **一卡一问**：卡片 = `配置名称` / `服务器路径` / `启动命令`，各一张，**不合并**（用户明确要求拆开）。
  成块靠 `--bg-subtle` 底色，不靠线（卡面与区块底本就不同色，再描边是把同一条边画两遍）；
  卡片内边距 `15px 16px 16px`、卡片间 14px。原先"一条淡线切两组"会让整张表单匀速、扁
  （用户口径：「太紧凑了」）。
- **卡片名后面不跟任何解释性文字**（卡片名下加 `· 左栏列表里怎么显示` 这类提示被用户删掉）。
  卡片头只放：序号 + 卡片名（`<label for=…>`，点它能聚焦输入框）+ `必填` + `?`，计数胶囊靠右。
  真正的说明一律收进 `?` 气泡（`aria-label` 也是完整句子）——**「按需展开」才是这些字的正确位置**。
  去掉提示文字后也**不要再补一根填充线**去"填满右侧"：卡片头本来就不需要占满，一根 400px 的线
  会让视觉重心从卡片名跑到线上。
- **卡片头兼作字段标签行**（一卡一字段时必须这么做）：「卡片名」和「字段名」是同一个词，
  写两遍就是纯噪声，还白占 23px×卡片数。做法：`group()` 挂 `g.head`，
  `field({ inHead: g })` 把「必填 / ? / 计数」append 进 `g.head`，字段自己只剩控件 + 错误行。
- **弹窗头只有一行**（标题 16px + 关闭），`align-items: center`。
  曾经加过「副标题」第二行（新增态「保存后它会出现在左栏配置列表里…」/ 编辑态「保存后立刻生效…」），
  **用户 2026-09-25 明确删掉** ⇒ `subtitle` 参数、`.modal-sub`、「`.modal-head-text` 包裹层」已全部移除。
  选择器底部那句 `pick-note`（「目录来自 prod-web-01 · 点目录名进下一级，点「用这个目录」选中当前这一层」）
  同批删掉 —— 它说的两件事分别是废话（目录名带箭头）和标题里已有的信息（机器名在弹窗标题里）。
- **界面能自证的，不要再配一句话解释**（用户先后删过三处：卡片名后的说明、弹窗副标题、选择器底部说明）。
  反复出现的形态是"替 UI 做注解" —— 按钮文字 / 列名 / 当前路径已经把答案写在那儿了，再补一句就是噪音。
  解释性文字的正确位置是 `?` 气泡这类**按需展开**处。
- **命令列表要有常驻列名行**（`操作名称 / 命令 · 从上到下依次执行`），且 placeholder 让位给示例
  （`重启服务` / `systemctl restart pay-api`）—— 列名给了语义，placeholder 再写一遍就是重复。
  列名必须放进**滚动区里面**并 `sticky; top:0` + 同色背景：放外面等于"用 padding 去补滚动条占位"——
  滚动条只在溢出时出现，补了就在不滚动时反向错位（实测列宽差 2px）。
  配套：行距改用 `margin-top` 而非 `gap` —— flex `gap` 会连表头一起算，sticky 时留出的那条缝会漏出滚过去的行。
- **多条目字段存的类型要和初始数据同型**：`onConfirm` 曾把 `cmd` 存成 JSON **文本**，而 `cmdEditor` 读初值写的是
  `Array.isArray(init) ? init : []` ⇒ 新建一条配置再点「编辑」，命令列表是空的，保存就把原来填的命令清掉了。
  **"存文本、读只认数组"这类不对称，一定会有人漏写** ⇒ 统一存结构化数组 + 读取一律走 `cmdList()`（数组/文本都吃）。
- 宽度 660px（`操作名称 108px + 命令` 两列不互挤，路径与常用值 chip 也才排得下一行 —— chip 折行会白白多占一行高），
  `max-height: 94vh` + `@media (max-height: 800px)` 收节奏（"收一档"不是"收紧"：收完仍要留得住卡片感与字段间距）。
  输入框 9px/13px 内边距、13px 字号起，字段间 14px。**拆卡片前先算总高**：多一张卡 ≈ +78px，
  三张卡 + 900 视口实测 839/846，已经贴上限。
- **响应式档位要不要提特异度，取决于它在样式表里相对基规则的位置** —— 同一文件里可以两种都有：
  `@media (max-width: 560px)` 写在弹窗区块**之前** ⇒ 与基规则同特异度会被压掉（`.form-group`/`.cmd-row` 的覆盖一直没生效过），
  必须写成 `.modal-form .form-group`；`@media (max-height: 800px)` 写在**之后** ⇒ 不用动。
  逐条查顺序很烦，**统一提一档更省心**。

## 顶栏导航 / 超级菜单（`导航-v4.html` 起）

- **导航可用宽 = 视口 − 319**（页面 padding 32 + logo 36 + 分隔 5 + 右侧按钮/头像 ~168 + 胶囊内边距 ~26）。
  **别用「`overflow-x:auto` + 隐藏滚动条」兜宽度**：实测 1100 视口会静默截掉末位 20px —— 无滚动条的横滚 = 内容消失。
- **导航 = 竖排书脊 + 刻度条**：图标在上、文字在下、每项底部一小段刻度，当前项刻度点亮并加长。
  它是侧栏圆盘那条「分段刻度」的**条版**（圆盘 = 环版，段数 = 分区数；顶栏 = 条版，格数 = 模块数）。
  收益主要是省宽：横排 2 字项 72px → 竖排 44px，9 项合计 **757 → 422px**
  ⇒ 旧的「≤1140 只留当前项文字」整条删掉（全 label 理论下限降到 ~741px）。
- **省宽有连带账**：项总宽压掉 335px 后若仍挤在左边，中间会空出 ~700px
  ⇒ 必须 `space-between` + 单元格 `flex: 1 1 0; min-width: 44px; max-width: 104px`，让刻度连成贯穿整条的尺。
  **"省下来的宽度不会自己变成留白之外的东西" —— 改宽度一定要回看这一条带。**
- **导航既不要居中、也不要 `space-between`**（1440 实测：`center` 把导航从 logo 旁拉开 207px；
  `space-between` 铺满后末项距右侧按钮只剩 10px）。**它属于"从 logo 出发的那一列"，右边那段留白是给页面级动作的呼吸。**
- **徽标三条**：① 必须留在项框内（`.nav-primary` 是 `overflow-x:auto` ⇒ 计算出的 `overflow-y` 也是 auto，
  越框像素会被裁还可能顶出竖滚动条）；② 锚点用「中线 + `margin-left`」而不是贴项框右边（项变等宽格后会把数字甩到 40px 外）；
  ③ 底色必须**不透明**（它压在图标笔画上，`--m-soft` 是 10% 透明色会透出来）。
- **选中态不铺实底**：9 个实眼底互相打架 ⇒ 当前项由「`--text-primary` + 字重 600 + 刻度点亮」表达
  （连带把 `nav-text-on` 从 5.79:1 提到 17.85:1）。等宽格的好副作用：切当前项时**项宽零跳动**。

### 超级菜单（顶栏下拉展示二级）

- **唯一站得住的理由是「≤900 侧栏隐藏后二级完全不可达」**（实测 900/800：侧栏、圆盘、平铺列三者皆不可见）。
  1440 下侧栏圆盘已承担二级，再挂就是第三个入口。**规模**：全部模块合计 65 个二级，最多的工作 12 个
  ⇒ 面板按 3 列算约 352×190px。
- **面板不能放进 `.nav-p-item` / `.nav-primary`**：后者 `overflow-x:auto` 连带 `overflow-y` 也是 auto ——
  实测挂进去后导航 `scrollHeight` 40 → 198、面板底越出导航底、命中测试拿到的是 `topbar`
  ⇒ 会被裁且顶出竖滚动条。**必须挂到 `.topbar`（已是 `position: relative`）或独立 fixed 层。**
- 落地五要点：① `.topbar-wrap` 要 `position: relative; z-index: 40`（否则 DOM 在后的 `.sidebar-wrap` z 30 会盖住面板）；
  ② 面板与顶栏之间那 4px 缝要有 `.mega::before` 做"桥"，否则横跨缝时离开顶栏、面板开始倒计时；
  ③ 定位 = 与触发项居中再**夹进顶栏**（末项「设置」的天然位置会越出右边界）；
  ④ `switchPrimary` 里要 `closeMega()`，否则面板会留着上一个模块的二级与"当前项"高亮；
  ⑤ 直达二级**不能**走 `handleRingClick`（它对"当前项"是 no-op，会吞掉这次点击）⇒ 另抽 `gotoLevel2(mod, idx)`。

## 侧边导航「展开圆盘 / 收起平铺」（`design/index/导航-v2.html`）

- **两种形态共用同一份 list / activeIdx / 点击处理器**（`renderRing` 算完直接 `renderRail(cfg, list, activeIdx)`）
  ⇒ "展开看到 A、收起看到 B"在结构上不可能发生。
- **收起态要补上「展开态由中心门承担的动作」**：`handleRingClick` 对当前项是 no-op ⇒ 当前项成死角；
  收起态点击先判 `i === activeIdx && item.children` 直接 `enterLevel3`。
- **名称只走悬停，别用「沿角度外推的气泡」**。踩过两次：① `--bx/--by` 算的是**相对圆心**的极坐标却当**相对图标中心**用，
  绝对半径变成 `R+RL` 飞出侧栏（症状＝"飘的没影"）；② 改对后仍别扭 —— 贴图标外沿要 ≥112、最宽 5 字名要 ≤112 才不被裁，
  正好顶牛，且每项方向不同看着就"歪"。⇒ 最终 **`.radial-caption` 固定在圆盘正下方**（stage 转 `flex-direction: column`），
  `max-width:100%` 吃满侧栏宽 —— 弦长 / 边界 / 换行三套约束一次性全部消失。
- **固定名称条 = 显隐两态、不参与布局**（`opacity + translateY` + `min-height` 占位）；点击后 DOM 换新元素、
  鼠标没动不会再触发 `mouseenter`，要用 `btn.matches(':hover')` 补一次，否则名称条会闪没。
- **名称退场后悬停要扛起全部提示** ⇒ 底色 `--m-soft` + 描边 + `scale(1.16)`，并给 `:focus-visible` 加**外置**焦点环。
- 收起态图标列**不要加 `overflow-y:auto`**（会裁掉浮出侧栏的提示）⇒ `flex:1 1 auto` + min/max-height，
  矮窗用 `@media (max-height: 720/620px)` 收节奏。

### 圆盘的比例、间距与「往上顶」

- **三个值全部由 JS 按项数推导**：`--r` 环半径 `radiusFor(n)`、`--icon` 图标直径 `iconFor(n,R)`、
  `--dial` 中心门**固定 53px**（唯一恒定锚点，环在它周围伸缩）。容器 = `calc(2*(var(--r) + var(--icon)/2 + 10px))`，
  那 10px 同时是选中项「向外咬合 5px」的余量。⚠️ 别再引独立的"外壳半径"（`--rl` 曾存在，光环盘删掉后只剩定容器尺寸一个用途）。
- **`radiusFor(n)` = `clamp(52, 44/(2·sin(π/n)), 74)`** —— 「项数少 ⇒ 盘小」。下界 52 = 中心门半径 + 图标半径 + **7px 缝**
  （26.5+18+7）；缝要跟着图标走，图标变大后同样的 4px 看着更挤。
- **`iconFor(n,R)` = `clamp(26, (2·R·sin(π/n) − 3)/1.155, 36)`**。n 大时弦长短，写死尺寸必然在
  「选中 1.15 倍 + 悬停 1.16 倍」的**相邻一对**上边缘相切、看成一块（实测写死时最坏净距只剩 0.2px）。
  **"写死的尺寸在项数变化时必然从防叠字变成纯信息损失" —— 本工作区第三次同源教训**（前两次：环上标签宽度、`auto-fill` 列宽）。
- **字形占比 0.54**（`svg{width: calc(var(--icon)*0.54)}`）：`--icon` 决定"放不放得下"，这个比例决定"看起来多大" ——
  纯色化后图标没有底色衬托，0.48 会让 36px 的按钮里只躺一个 17px 的字形、显得空。
- **容器宽度是硬约束**：`.radial` 居中在 `.sidebar` 内容盒里 —— 侧栏 240 → 内容 238；`≤1100px` 侧栏 220 → 内容 218
  ⇒ 容器 ≤ 218（当前最大 201）。想再放大图标，要么抬 R（吃余量），要么压 10px 咬合位。
- **`margin-top` 要跟着图标尺寸重算**：容器顶部空白 = 容器半宽 −（R + 咬合 5px + 半个图标），图标一变大它就变小 ⇒
  实测「副标题底 → 最上面那个图标顶」= 3.3~3.8px（当前 `margin-top: 1px`）。
- **弧 = 分段刻度，不是进度条**（`arcStops(n, activeIdx)`）：段数 = 分区数，已过的段填 `--m-main`、未到的留淡痕。
  **未填充的那几格是纯装饰**（总数由图标本身可见），不适用 3:1 图形门槛 —— 已在注释里显式声明。
- **选中项沿半径向外咬合 5px**（悬停 3px）：让"当前项"从盘面探出来而不只是换颜色；外推**增大**了与相邻项的净距。
- **圆盘存在的理由是"识别度"不是"效率"**（用户口径：「主要是看着和普通的千篇一律的不一样就行」）。
  别再拿"四列图标网格更省空间"否定它 —— 网格正是千篇一律的样板；纯色化后**圆盘是界面里唯一非矩形的结构**。
  正确方向是"让形状携带信息"（半径反映项数 + 分段刻度 + 咬合），不是换成更规整的排布。
- **侧栏宽度是量出来的**：逐档压低 `--sidebar-w`，在**每一个内容面板**里查 `scrollWidth > clientWidth + 1` 与按钮是否折行
  —— 实测下限 **210px**（205 时「新建任务」折两行）⇒ 取基准 **240 / ≤1100px 窄档 220**。"容器能收多窄"是个可测量量。

### 悬停浮层「画不出来」的两种原因（`getBoundingClientRect` 一个都测不到）

`rect` 正确、`opacity:1`，**不等于看得见**：① **被祖先裁**（`.sidebar.collapsed{overflow:visible}` 只放开一层，
外层 `.sidebar-wrap` 还是 `overflow:hidden`，按 64px 列宽剪掉）；② **被兄弟盖**（`.sidebar` 带 `backdrop-filter`
⇒ 它自己就是层叠上下文，提示的 `z-index` 出不去）⇒ 抬整列 z-index。
**判据必须是命中测试**：目标 `pointer-events` 临时改 `auto`，`document.elementsFromPoint(x,y)` 的第 0 个要是它自己。
实测：修前收起态提示 = **1.00:1**（量到的是主内容卡），修后 11.10:1。

## 运维两页的顶栏（`日志` / `部署`）—— 同一套读法，改一处要对齐另一处

三段：① 身份（图标方块 + 项目名 + 分区标签）② 上下文 ③ 状态与动作。
- **分区名做成标签**（`.viewer-scope`，10.5px/800，薄染底 + 主题色文字），**不拼进标题**——
  拼进去会占掉半个标题的宽度（「支付系统重构 · 日志」→「支付系统重构」+ 标签「日志」）。
- **身份方块 28×28**：薄染混**顶栏自己的底色**（不混 transparent）+ 1px 同色描边，图标 15px 内联 SVG。
- **动作区三颗按钮统一 30px**：`刷新` = 有框的小按钮（`.log-tool` + border + card 底，图标 13px）；
  `主题` = 30px 方按钮；`关闭` = `.icon-btn.danger`（方形图标按钮，平时中性、hover 才转 danger-fg）。

  而不是由按钮决定，轨道看着还比按钮大一号。日志页 50px 单行 = 10 + 30 + 10。
- 文案与部署页统一为「更新于 HH:MM」；≤560px 收起它（部署页同一处理），让位给身份与动作。

## 结构自检与静默失效（原 `MEMORY.md`「踩过的坑」全表）

1. **`[hidden]` 会被 author 的 `display` 覆盖** ⇒ 全局 `[hidden]{display:none!important}`。
2. **折叠动画别写死 `max-height`** ⇒ `display:grid; grid-template-rows: 1fr/0fr` + 子元素 `overflow:hidden;min-height:0`。
3. **`position:fixed` 子元素受祖先层叠上下文限制** ⇒ 遮罩放进同一个层叠上下文。
4. **不要用「逐块正则替换」改多块同构结构**：`[\s\S]*?` 会从**前面的块**跨过来匹配、吞掉标签 ⇒ **整块重建或从后往前处理**；改完做两道自检（标签配平 + 逐块行数）。**只跑截图看不出来。**
5. **别用「按钮下标」对齐「内容下标」** ⇒ 两侧带 `data-*` 按值匹配 + `syncXxxButtons()`。
6. **grid 容器不写 `grid-template-rows` 会被子项撑破**；**空态量不出来，内容变多才暴露** ⇒ 显式 `minmax(0,1fr)`；**几何回归必须覆盖"内容最多 / 状态最靠后"那一档**。
7. **只验证"有没有某个 class"查不出状态错**，必须逐条打印每个元素的 `class / 时间列 / 圆点`。
8. **量错对象**（完整失败模式表 → 技能 `html-ds-delivery-verify`）：截图前关动画；「元素在视口外」不一定有溢出告警（按"在最近滚动祖先的可视区内"判）；测"点击后状态"先过滤掉会下钻的项；判"浮层可见"按 hovered 项取；量几何前确认目标 scope **可见**（`display:none` 里 rect 全是 0）。
9. **媒体查询里的覆盖写在基规则之前会静默失效**（同特异度后者胜出）⇒ 修法是**提高特异度**，不是挪位置；验证只有一条：**读 computed 值**。
10. **CDP 探针报 `ECONNREFUSED 127.0.0.1:<port>` 先看端口是不是上一个实例的**（`PROFILE` 指错目录会去连已关闭的端口）。
11. **改 HTML/CSS 的三类"静默自伤"，页面都看不出来**：① **切两刀删 CSS** ⇒ 中间成**孤儿声明**，浏览器丢弃、渲染正常（判据：去注释后算花括号深度，**depth 0 处出现 `a-b: v;` 形状的行 = 孤儿**）；② **`const` 的 TDZ**：函数**在定义处就被调用**、用到的 `const` 在后面 ⇒ 从那一行起**全不执行**（判据：探针第一条断言必须是「首屏无 `Runtime.exceptionThrown`」）；③ **对象字面量里的"兄弟"看不见彼此的 `let/const`**：写时不报错，点"创建"才炸、表单还关掉了 ⇒ **共享状态声明在字面量之外**。
12. **批量换令牌时 `color:` 是 `border-color:`/`outline-color:` 的子串**：一句 `replace('color: var(--x)')` 会连带把**图形档**拖进**文字档**（肉眼与截图都看不出）⇒ 收尾反查 `(border|outline|background)-color: var(--…-ink)` 逐条回正。同源：`--m-fill` ⊂ `--m-main`、`--bg-card` ⊂ `--bg-card-hover`。
13. **同一份数据的「写」与「读」类型必须对称**：写入存 JSON 文本、读取只认数组 ⇒ 新建后编辑读回是空、保存即清空。**类型统一在写入侧解决。**
14. **同一能力的第二份实现要抽公共部分**：同一套目录选择器在两页各一份，差异只在"选中的落点"与"找不到时的回退" ⇒ 再要第三个入口就该抽"共用目录树 + 可配置的选中语义"。
15. **结构插入"差一行"会把新内容嵌进上一个元素**：`lines[i:i]=block` 的 `i` 若指的是收口 `</div>` **那一行本身**，必须写 `i+1`。后果**看起来完全正常** ⇒ 插入后断言"没有嵌套的同类元素"。
16. **"方向"类错误在列表里是静默的**：新的在上 ⇒「最近 N 行」= DOM **前** N 行。写成后 N 行 ⇒ 行数对得上、时间列也在走，只是**给你看的是最旧的那批** ⇒ 断言载入那批的**首个/末个**值。
17. **手改过文件又从备份重放补丁 = 那处手改被静默回滚**：手动 `Edit` 要**同时写回补丁脚本**，否则下次 `cp 备份 && python patch.py` 悄悄抹掉。
18. **两个控件等高别写死 px** ⇒ `align-self: stretch` 跟着"这一行最高的那个"走。实测 32 vs 33 → stretch 后 33=33。
19. **顶栏里推进去的"胶囊"要跟按钮同高**（都写 30px）：折行后第一行高度由最高的那个决定。
20. **`getComputedStyle` 的颜色有第二种形态**：`color-mix()` 的计算值是 **`color(srgb 0.89 0.96 0.94)`（分量 0~1）**，不是 `rgb()`。探针按 `/\d+/g` 抓数字当 0~255 用 ⇒ 读成"接近全黑"；只匹配 `rgba?()` 的找底色逻辑还会**跳过它**去拿更亮的祖先 ⇒ 两条路都是**假通过**（实测同一对颜色：错解析 3.81 / 正确 4.94）。修法与片段见技能 `html-ds-delivery-verify`「图标体检」，并断言"审了多少类"—— 数量对不上就说明有元素没被审到。


## 运维两页的「分组」选择器（`日志` / `部署`）—— 一套控件，两页必须长得一样

新增/编辑时"归到哪一组"用的都是：**一排单选胶囊 + 行尾一个虚线「＋」**（不是下拉）。
尺寸两页统一：胶囊 `padding: 4px 11px` / 圆角 999 / 11px 字；＋ `30×25`；展开的输入框 `104×25`。
- 选中态 = **主题色描边 + 10% 薄染底 + 文字提色**（底色差单独只有 1.06:1 = 状态不可见）。
- ＋ 是 `1px dashed`，描边用 **`--border-field`**（≥3:1 的"控件边界"档，不是 `--border-strong`）
  —— 这个令牌原先只有部署页有，日志页在本次补齐（浅 `#7F899B` / 深 `rgba(255,255,255,.36)`）。
- 点 ＋ 在**同一位置**换成输入框；回车/失焦提交、**空名 = 取消**、**Esc 要 `stopPropagation()`**
  （否则文档级监听会把整张弹窗关掉）。
- **兜底组永远在最后**（部署页「其它」/ 日志页「自定义」）：新建的组插在它之前，
  两处（对话框胶囊、左栏组列表）顺序才一致。
- 数据侧：分组的身份就是**名字**，按名字查 DOM 里的组（没有就建）—— 不另存清单。

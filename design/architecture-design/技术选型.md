针对个人笔记系统（Tauri + React + Rust），技术栈整理如下。核心思路是 **Markdown 文件为源、SQLite 为索引、Git 为同步**，兼顾数据安全与知识图谱能力。

### 🗄️ 存储与数据层

**Markdown 文件为源，SQLite 仅作索引。** 笔记以 `.md` 文件存储在磁盘，SQLite 索引可随时从文件重建。`notify` 监听文件变更，防抖后更新索引，支持外部编辑器（如 VS Code）的修改被自动检测。SQLite 使用 `rusqlite` 的 `bundled` 特性，无需系统安装 SQLite。

**Rust 后端核心依赖：**

| 类别          | Crate                              | 说明                                                    |
| ------------- | ---------------------------------- | ------------------------------------------------------- |
| 数据库        | **rusqlite** (bundled) 或 **sqlx** | `bundled` 免系统依赖；sqlx 支持编译期查询验证           |
| 文件监听      | **notify**                         | 后台线程监听工作区，防抖防止频繁写入                    |
| Markdown 解析 | **pulldown-cmark**                 | 提取 frontmatter、任务、`[[wikilinks]]`，纯 Rust 高性能 |
| 全文搜索      | **SQLite FTS5**                    | 虚拟表实现全文索引，支持中文分词扩展                    |
| IPC 类型安全  | **tauri-specta**                   | 从 Rust 命令自动生成 TypeScript 绑定                    |
| 异步运行时    | **tokio**                          | 文件 I/O、索引重建等异步任务                            |

### ⚛️ 前端技术栈

| 类别     | 选型                            | 说明                                            |
| -------- | ------------------------------- | ----------------------------------------------- |
| 框架     | **React 19 + TypeScript**       | React Compiler 自动优化                         |
| 构建     | **Vite**                        | Tauri 官方推荐                                  |
| UI 组件  | **shadcn/ui + Tailwind CSS v4** | 高度可定制，笔记场景需要深度定制 UI             |
| 编辑器   | **TipTap**（ProseMirror）       | 支持 WYSIWYG 与 Markdown 源码模式，扩展生态丰富 |
| 状态管理 | **Zustand**                     | 轻量，管理编辑器与启动状态                      |
| 数据获取 | **TanStack Query**              | 管理来自 Rust 后端的查询数据                    |

### 🕸️ 知识图谱方案

知识图谱的**数据来源于 `[[wikilinks]]`**。`pulldown-cmark` 解析 Markdown 时提取链接关系，存入 SQLite 的关系表中。图谱的边来自双向链接，节点是笔记本身。

**可视化推荐 Cytoscape.js**：交互式图渲染，支持 dagre 分层布局，适合笔记之间的关联展示。数据层无需引入 Neo4j 等重型图数据库，SQLite 的 `WITH RECURSIVE` 查询即可实现图遍历。

### 🔄 同步与迁移

**Git 作为异步同步层**：本地 Markdown 文件是唯一真相来源，`git commit` + `git push` 在后台定时或网络恢复时执行。换电脑时 `git clone` 恢复所有笔记，SQLite 索引启动时从 Markdown 文件自动重建。SQLite 数据库不提交到 Git，避免体积膨胀。

### 📋 完整速查表

| 层面               | 选型                                          |
| ------------------ | --------------------------------------------- |
| 桌面外壳           | Tauri v2                                      |
| 前端框架           | React 19 + TypeScript + Vite                  |
| UI 组件            | shadcn/ui + Tailwind CSS v4                   |
| 编辑器             | TipTap                                        |
| 状态管理           | Zustand                                       |
| 数据获取           | TanStack Query                                |
| 数据存储           | Markdown 文件（源）+ SQLite（索引）           |
| Rust 数据库        | rusqlite (bundled)                            |
| Rust 文件监听      | notify                                        |
| Rust Markdown 解析 | pulldown-cmark                                |
| Rust 全文搜索      | SQLite FTS5 + 中文分词扩展                    |
| IPC 类型安全       | tauri-specta                                  |
| 知识图谱           | pulldown-cmark 提取链接 + Cytoscape.js 可视化 |
| 同步               | Git（本地提交 + 异步推送）                    |

这套方案的核心优势是**数据永不锁定**：Markdown 文件可用任何编辑器打开，SQLite 索引可重建，Git 提供版本历史和跨设备迁移。知识图谱从双向链接自动构建，无需额外维护图数据结构。

可以，按这六个顶层模块来设计：

```text
生活 / 工作 / 学习 / 项目 / 知识库（可选） / 设置
```

核心关系：

- **生活、工作**：两个业务域，各自独立页面、菜单、权限。
- **学习**：独立模块，跨生活和工作，管输入、笔记、复习、输出。
- **项目**：统一执行层，一套模块，三个入口：生活项目、工作项目、学习项目。
- **知识库**：可选，长期沉淀层；MVP 可先合并到学习。
- **设置**：全局支撑，管账户、模块、主题、通知、数据、集成、隐私。

## 1. 生活模块

**定位**：个人生活管理，关注健康、习惯、财务、家庭、日程、心情。

**路由前缀**：`/life/*`

**菜单/页面**：

| 页面     | 路径              | 内容                                 |
| -------- | ----------------- | ------------------------------------ |
| 概览     | `/life/dashboard` | 今日日程、习惯、待办、心情、支出摘要 |
| 日程日历 | `/life/calendar`  | 生活事件、纪念日、家庭安排           |
| 习惯打卡 | `/life/habits`    | 习惯列表、连续天数、打卡记录         |
| 健康运动 | `/life/health`    | 体重、睡眠、运动、饮食               |
| 财务记账 | `/life/finance`   | 收支、预算、分类统计                 |
| 日记心情 | `/life/journal`   | 日记、心情、标签、回顾               |
| 生活目标 | `/life/goals`     | 年度/季度/月度目标                   |
| 家庭事务 | `/life/family`    | 家庭待办、账单、纪念日               |
| 生活项目 | `/life/projects`  | 调用项目模块，`scope=life`           |
| 生活设置 | `/life/settings`  | 生活模块偏好                         |

**核心数据**：  
`LifeEvent`、`Habit`、`HabitLog`、`HealthLog`、`Transaction`、`Budget`、`Journal`、`LifeGoal`、`FamilyTask`

**主题**：绿色 / 暖色，柔和、记录感。  
**权限**：`private` / `family`。

---

## 2. 工作模块

**定位**：职业工作管理，关注任务、项目、会议、文档、OKR、工时、复盘。

**路由前缀**：`/work/*`

**菜单/页面**：

| 页面     | 路径              | 内容                           |
| -------- | ----------------- | ------------------------------ |
| 工作台   | `/work/dashboard` | 今日任务、会议、项目进度、待办 |
| 任务看板 | `/work/tasks`     | 待办、进行中、已完成、优先级   |
| 工作项目 | `/work/projects`  | 调用项目模块，`scope=work`     |
| 日历会议 | `/work/calendar`  | 工作日程、会议安排             |
| 文档索引 | `/work/docs`      | 工作文档索引，不存正文         |
| 联系人   | `/work/contacts`  | 客户、同事、合作方             |
| OKR/KPI  | `/work/okr`       | 目标、关键结果、绩效指标       |
| 工时统计 | `/work/timesheet` | 工时记录、项目耗时             |
| 周报复盘 | `/work/review`    | 周报、月报、复盘               |
| 工作设置 | `/work/settings`  | 工作模块偏好                   |

**核心数据**：  
`WorkTask`、`Meeting`、`WorkProject`、`WorkDocIndex`、`Contact`、`OKR`、`TimeLog`、`WeeklyReport`

**主题**：蓝色 / 冷色，效率、执行感。  
**权限**：`work-internal` / `confidential`。  
**原则**：工作文档正文留在公司工具，个人系统只存索引、链接、脱敏摘要。

（这条管的是 `work_doc` 那批 —— 公司 wiki / 部署 / 会议纪要，属于**保密**要求。
项目模块的 `project_document` 另说：`source='local_md'` 的那些**正文就是本地 `.md` 文件**
（`<documents 根>/<projectId>/`），库只存索引与文件坐标。判据见 `../sql-design/全局架构.md` §三 / §九。）

## 3. 学习模块

**定位**：个人学习成长，管目标、技能、资源、笔记、复习、实践、输出。

**路由前缀**：`/learning/*`

**菜单/页面**：

| 页面     | 路径                  | 内容                                   |
| -------- | --------------------- | -------------------------------------- |
| 概览     | `/learning/dashboard` | 本周学习、待复习、进行中资源、实践项目 |
| 学习目标 | `/learning/goals`     | 季度/年度目标、截止时间、进度          |
| 技能地图 | `/learning/skills`    | 语言、框架、领域、熟练度               |
| 资源库   | `/learning/resources` | 书、课程、文档、视频、文章             |
| 笔记卡片 | `/learning/notes`     | 永久笔记、文献笔记、闪卡               |
| 复习计划 | `/learning/review`    | 间隔重复、待复习队列                   |
| 实践项目 | `/learning/projects`  | 调用项目模块，`scope=learn`         |
| 输出分享 | `/learning/output`    | 博客、分享、开源、总结                 |
| 学习设置 | `/learning/settings`  | 学习模块偏好                           |

**核心数据**：  
`LearningGoal`、`Skill`、`Resource`、`Note`、`ReviewCard`、`Practice`、`Output`

**主题**：紫色 / 青色，成长、探索感。  
**权限**：默认私有，公开输出单独加 `visibility: public`。  
**与工作交互**：工作中遇到问题 → 创建学习主题 → 学习完成后脱敏沉淀。  
**与项目交互**：学习实践走项目模块，`scope=learn`。  
**与知识库交互**：成熟笔记升级为知识库永久笔记。

## 4. 项目模块

**定位**：统一执行层，跨生活、工作、学习。一套组件、一套 API、一张表，用 `scope` 隔离。

**路由入口**：

```text
/life/projects       生活项目，scope=life
/work/projects       工作项目，scope=work
/learning/projects   学习项目，scope=learn
/projects            可选：跨域总览，需权限
```

**菜单/页面**：

| 页面      | 内容                                          |
| --------- | --------------------------------------------- |
| 项目列表  | 按 scope 过滤，生活卡片 / 工作表格 / 学习看板 |
| 项目详情  | 概览、任务、里程碑、文档、笔记、时间线        |
| 任务      | 项目内任务，关联负责人、状态、优先级          |
| 里程碑    | 关键节点、截止时间                            |
| 文档      | 文档索引、外部链接、脱敏摘要                  |
| 笔记      | 关联学习笔记、工作笔记、生活记录              |
| 时间线    | 项目事件、变更、复盘                          |
| 工时/实践 | 工作工时、学习实践记录                        |
| 风险/复盘 | 工作风险、学习复盘、生活总结                  |

**核心数据**：

```ts
Project {
  id
  ownerId
  scope: 'life' | 'work' | 'learn'
  name
  description
  status
  priority
  progress
  visibility
  tags
  startDate
  dueDate
  repoUrl
  docsUrl
  meta
}
```

关联表：`Task`、`Milestone`、`Document`、`NoteLink`、`TimeLog`、`Risk`、`Review`。  
**所有关联表都带 `scope`，后端强制过滤。**

**不同 scope 差异**：

| scope | 默认视图  | 重点                           |
| ----- | --------- | ------------------------------ |
| 生活  | 卡片      | 进度、预算、习惯、纪念日       |
| 工作  | 表格/看板 | 客户、团队、里程碑、工时、风险 |
| 学习  | 看板      | 目标、技能、笔记、实践、输出   |

**权限**：  
生活 `private/family`，工作 `work-internal/confidential`，学习 `private/public`。

## 5. 知识库（可选）

**定位**：跨模块长期知识沉淀，永久笔记、主题索引、双链、引用、输出。  
**建议**：MVP 先合并到学习模块，笔记量大了再拆。

**路由前缀**：`/knowledge/*`

**菜单/页面**：

| 页面       | 路径                   | 内容                       |
| ---------- | ---------------------- | -------------------------- |
| 全部笔记   | `/knowledge/notes`     | 所有永久笔记               |
| 主题       | `/knowledge/topics`    | 按领域/技术/主题组织       |
| 标签       | `/knowledge/tags`      | 标签体系、筛选             |
| 双链图谱   | `/knowledge/graph`     | 笔记关联、知识网络         |
| 收藏       | `/knowledge/favorites` | 重要笔记                   |
| 归档       | `/knowledge/archive`   | 过期、低价值、历史笔记     |
| 导入导出   | `/knowledge/io`        | Markdown、Obsidian、Notion |
| 知识库设置 | `/knowledge/settings`  | 偏好设置                   |

**核心数据**：  
`KnowledgeItem`、`Topic`、`Tag`、`Link`、`Attachment`

**交互**：

- 学习笔记成熟 → 升级为知识库永久笔记。
- 工作通用知识 → 脱敏后进知识库。
- 项目产出 → 沉淀为知识库条目。
- 知识 → 反向关联到项目、任务、笔记。

**权限**：`private` / `public`。  
**红线**：工作机密、公司代码、客户数据不入库。

## 6. 设置模块

**定位**：全局配置中心，不随模块切换，但包含各模块子设置。

**路由前缀**：`/settings/*`

**菜单/页面**：

| 页面       | 路径                      | 内容                                    |
| ---------- | ------------------------- | --------------------------------------- |
| 账户与安全 | `/settings/account`       | 登录、密码、2FA、设备                   |
| 模块管理   | `/settings/modules`       | 开启/关闭生活、工作、学习、项目、知识库 |
| 主题与外观 | `/settings/appearance`    | 主题、暗色、布局、字号                  |
| 通知提醒   | `/settings/notifications` | 日程、习惯、任务、复习提醒              |
| 数据与备份 | `/settings/data`          | 备份、恢复、同步                        |
| 导入导出   | `/settings/import-export` | Markdown、CSV、JSON                     |
| 集成与 API | `/settings/integrations`  | GitHub、日历、Notion、Webhook           |
| 权限与隐私 | `/settings/privacy`       | 可见性、脱敏、审计                      |
| 快捷键     | `/settings/shortcuts`     | 全局快捷键                              |
| 关于       | `/settings/about`         | 版本、更新日志                          |

**核心数据**：  
`UserPreference`、`ModuleConfig`、`Integration`、`Backup`、`AuditLog`

**功能**：

- 控制六个模块的显示与隐藏。
- 配置每个模块的菜单、主题、默认视图。
- 管理数据导入导出、备份、同步。
- 管理 API Token、Webhook、第三方集成。
- 隐私过滤：工作机密、生活隐私、学习公开范围。

## 模块间交互总览

| 从   | 到     | 交互                             |
| ---- | ------ | -------------------------------- |
| 生活 | 项目   | 生活项目 `scope=life`            |
| 工作 | 项目   | 工作项目 `scope=work`            |
| 学习 | 项目   | 学习实践 `scope=learn`        |
| 工作 | 学习   | 工作问题 → 学习主题，脱敏后沉淀  |
| 学习 | 知识库 | 成熟笔记 → 永久笔记              |
| 工作 | 知识库 | 通用知识 → 脱敏入库              |
| 项目 | 知识库 | 项目产出 → 知识条目              |
| 设置 | 所有   | 模块开关、主题、权限、通知、数据 |

## MVP 落地顺序

1. **生活**：概览、习惯、日程、财务。  
2. **工作**：工作台、任务、工作项目、日历。  
3. **学习**：目标、资源、笔记、学习项目。  
4. **项目**：统一 `ProjectModule`，支持 `life / work/learn` 三个 scope。  
5. **知识库**：先合并到学习，加“永久笔记”类型。  
6. **设置**：账户、模块管理、主题、数据导出。

一句话总结：  
**生活和工作是业务域，学习是成长域，项目是执行域，知识库是沉淀域，设置是全局支撑。项目模块统一，用 `scope` 隔离；学习独立，知识库可选；工作机密不入个人库。**

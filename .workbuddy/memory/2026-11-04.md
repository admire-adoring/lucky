## 密码认证也验得了（SSH_ASKPASS，不装 sshpass）

- 做法：临时目录 0700 里写一个 `askpass.sh`（内容只读 `$LUCKY_SSH_PASSWORD`），
  `Command` 设 `SSH_ASKPASS` / `SSH_ASKPASS_REQUIRE=force` / `DISPLAY=:0` + 密码环境变量；
  密码不进 argv、不落盘，跑完 `Drop` 删目录。需 OpenSSH ≥ 8.4（本机 10.5p1）。
- 关键：密码档必须 `BatchMode=no` —— 开着等于禁止密码交互，askpass 根本不会被调用；
  另加 `PubkeyAuthentication=no` + `PreferredAuthentications=password,keyboard-interactive` + `NumberOfPasswordPrompts=1`。
- 提权：密码登录用 `sudo -S -p ''`、密码从 ssh stdin 喂（`Stdio::piped` 写一行）；
  密钥登录仍是 `sudo -n`。`su` 仍需 tty，失败文案直说。
- `draft::run_ssh(cred, target, port, script, stdin_line)` 取代原 `ssh()`，`Credential::{Key(PathBuf), Password(String)}`。
- 测试：askpass 脚本能吐密码 + 目录自删（draft 6 项全过）。
- 遗留：保存后的「测试连接」走的 `srv_probe` 读不到密码 —— 表单里的密码从不写钥匙串
  （`cred_ref` 全表为 null，keyring 目前只有 project/account.rs 在用）。要统一得先做凭据入库。

## 部署页补上那两条「未做」：上传断点续传 + 并发、ask 命令喂输入

**上传**（`remote.rs::upload`）

- 落地改成"先写 `<目标>.part`，字节数对上才 `mv`"：传一半断掉不会在正式路径留下半个包；
  重跑时 `.part` 的长度就是进度，本地 `seek` 到那儿，远端 `cat >>` 追加。
- 三态 `plan(have, total)`：`None` 或 `have > total` → 清掉重传（残片比源文件还长说明不是这次的进度）；
  `have == total` → 上次写完没来得及改名，只做收尾；其余 → 从 `have` 续。
  单测 `upload_resumes_only_from_a_credible_partial`。
- 收尾一段在远端同一次调用里做完：`wc -c` 比对 → 不等就 `exit 3` → 相等才 `mv -f`。
  半个包出现在正式路径上比没有更糟。
- 本地 shell 实测过分片拼接：16 字节文件先写 6 字节残片、`tail -c +7` 续上，最终字节完全一致。

**并发**（`term.rs`）

- 原来的 `JOB_LOCK` 锁的是"整趟执行"，把并发一起挡死了。真正需要串行的只有**首次**建主连接
  （两个 ssh 同时去建同一个 socket，后到的会把自己的判断变成"已存在"然后失败）。
  改成 `warm()`：`WARM: Mutex<Vec<String>>` 记已预热的 session id，只有未预热时才持 `JOB_LOCK`
  跑一次 `true`；建完就放开。连接断了（code 255）在 `deliver` 里 `mark_cold`，下次重新预热。
- 前端 `stepUpload` 换成 3 个 worker 抢同一个队列，`failed` 一旦置位就停止取新任务。

**ask 喂输入**（`term.rs::run_job_fed` + `remote.rs::run(feed)`）

- 命令走 argv（`sh -c` 包一层），stdin 留给输入，`ssh` 加 `-tt` 强制分配远端伪终端 ——
  `su` / `passwd` / `ssh` 读的是 `/dev/tty`，没有 pty 就只读到 EOF。
- 用 python `pty.fork` 复现过：写 `secret\n` 后 `read` 拿得到，回显是 `secret\r\n`。
  顺带确认写完立刻 EOF 也不会丢那一行（`got:[secret]`），但会在输出里回显 `^D` + 两个退格。
- `outcome_scrubbed`：逐行比对 feed 的内容换成 `***`，并清掉 `\r` / `\x04` / `\x08`
  （pty 的 EOF 痕迹）。密码回显进了日志就等于泄露，这一步不是可选项。
- `ExecOutcome.fed` 出门：带输入时远端 stderr 已并进 stdout，前端据此不再重复打 stderr、

  - 第二个 effect：正文到货且还挂着"待补种"且 md 是空白 ⇒ `resetTo(mdOfBlocks(body))`，
    并 `setHistToken(t+1)` —— **可视面只认 `paint`（跟 md 会跳光标），不 bump 的话数据在、纸还是空的**。
  - 已经敲过字就不补（`md.trim() !== ''` ⇒ 放弃补种），不拿文件盖掉用户输入。

  不给一张可编辑的空纸（那上面敲的字一保存就会盖掉原文）。
